# WorkLog 입체 메인 화면

2026-11-07 사용자가 Hallmark로 로그인 전 메인을 입체적이고 역동적인 근태관리 화면으로 바꾸도록 요청했다. 2026-11-09 후속 요청에 따라 메인에 보이던 로그인 폼을 없애고 첫 화면에서 기본 관리자 계정으로 입장한다. 다른 테스트 사원은 업무 화면에서 선택한다.

## 범위와 계약

- 대상은 `AuthPages.tsx`의 `demo` 화면과 데모 업무 화면의 사번 전환이다. 일반 로그인·초대·복구·운영자 화면은 기존 경로를 사용한다.
- **WorkLog 시작하기**는 서버가 반환한 `demoAccounts`에서 `99999`와 `ATTENDANCE_ADMIN`이 모두 맞는 계정을 골라 기존 `/login`으로 POST한다. `email`·`password`와 CSRF는 숨은 폼 필드로 제출한다. 기본 계정이 없으면 버튼을 비활성화하고 안내한다. 로그인 오류와 로그아웃 알림은 첫 화면에서 표시한다.
- 기본 관리자 로그인은 기존 성공 경로 `/me/home`을 따르고 데모 홈의 첫 역할은 보유 중인 `담당자`로 선택한다. 업무 경로에 맞는 기존 역할 선택과 일반 환경의 기본값을 우선한다.
- 데모 업무 화면의 상단 **사번 변경**에서 `GET /demo`로 서버가 제공한 합성 사원 목록을 읽는다. 사번과 이름을 선택하고 전환을 확정하면 기존 로그인으로 전체 문서를 새로 연다. 서버가 새 세션과 현재 권한을 구성하며, 고정 승인자는 기존 성공 경로 `/approvals`로 이동한다.
- 공개 후보의 `publicDemo`, 공유 가상 자료·개인정보 입력 금지 안내와 공개/로컬 footer 구분을 보존한다.
- DB·API·권한·계산 규칙·의존성·설정 변경은 없다.

## 디자인

- 제목: 기존 `근무는 한눈에. 관리는 간결하게.`를 `일하는 하루, 기록이 되다.`로 변경한다.
- 설명: `출퇴근부터 휴가까지, 우리 팀의 하루를 연결하는 근태관리.`로 제품의 용도를 밝힌다.
- 아이보리 배경, 차콜 글자와 액션, 코럴 달력, 녹색 휴가 표식을 사용한다. 기존 WorkLog 이름·W 표시와 한국어 시스템 서체를 유지한다.
- 첫 화면은 제목·설명·시작 버튼과 CSS 입체 주간 달력·시계·출퇴근 오브제다. 다음 영역은 출퇴근·근무 일정·휴가 소개와 푸터다.
- 오브제는 근무와 휴가를 표현한 장식이다. 전체에 `aria-hidden`을 적용하며 화면 독자는 실제 설명과 시작 버튼을 읽는다.
- 모션은 최초 1.2~1.8초의 위치·회전 변화와 달력의 hover 기울기다. 무한 반복하지 않고 `prefers-reduced-motion: reduce`에서는 애니메이션·전환·hover 기울기를 제거한다.
- `DemoLanding.css`의 `:root`에 전용 색상 토큰을 정의하며 기존 업무 테마 토큰은 바꾸지 않는다. `design.md`의 장식·모션 제한에 대한 이번 사용자 요청의 예외는 이 메인 화면에만 적용한다.
- 최대 컨테이너1240px. 900px 이하에서는 단일 열, 360px 이하에서는 오브제 축소를 적용한다. `html/body`의 기존 `overflow-x: clip`과 초점 표시를 유지한다.

## 2026-11-09 진입과 전환 검증

- 개발 프런트 전체 345개와 TypeScript·Vite 빌드를 통과했다. 첫 화면은 기본 사번 `99999`로만 제출하며, 다른 합성 사번은 상단 모달에서 선택하고 확정해야 제출된다.
- 합성 HTTP 테스트 3개와 Chromium의 PC·390px·320px 관리자 → 승인자 → 관리자 흐름을 확인했다. `/login` POST 9회에 합성 CSRF·세션 교체·이전 세션 차단·이전 권한 메뉴 제거를 검증했다. 화면 22개와 검증 JSON은 `target/hallmark-tools/worklog-entry-20261109/`에 남겼다.
- 기존 `/login`과 세션 처리를 사용했다. 현재 로컬 Docker 데몬에 연결할 수 없어 PostgreSQL을 사용하는 Java 인증 통합 테스트는 재실행하지 않았다.
- 현재 공개 자산은 `89da774`와 일치한다. 이 버전을 기준으로 공개 전용 안전 안내와 날짜 UI를 보존한 별도 후보를 통합했다. SSH 연결이 시간 초과되어 공개 반영에는 VPS 콘솔 접근이 필요하다.
