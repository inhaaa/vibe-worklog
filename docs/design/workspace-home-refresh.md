# 홈과 업무 화면 개편

- 로그인 후 기본 화면은 `GET /me/home`이다. PC의 사이드바와 모바일 상단에서 WorkLog 로고를 누르면 홈으로 돌아간다. 공개 소개와 데모 결재자 빠른 진입은 기존 경로를 사용한다.
- 홈의 React 페이지는 `workspace/home`이며 기존 `WorkspaceQueries.home`의 `workspaceHome`을 사용한다. 오늘 출퇴근, 이번 주 일정, 연차 잔여와 최근 신청을 본인 범위에서 표시한다. 서버 응답은 화면에 쓰는 요약으로 제한한다. 누락된 정보는 빈 상태로 안내한다.
- 홈은 환영 영역과 근무 대시보드를 표시한다. 그 밖의 업무 화면은 공통 인사 헤더를 한 번 표시한다. 본인 및 열람 권한이 있는 대상 사원은 기존 상세 헤더를, 회사·관리 목록은 로그인한 사원의 이름과 회사 요약을 사용한다.
- 근태 신청 모달은 상단 결재선과 신청서 입력을 함께 보여 준다. 결재선은 조회 및 미리보기 응답을 따르며 제출 직전 확인을 유지한다.
- 차콜과 블루를 유지한다. 차분한 바탕 위에 홈 환영 영역과 인사 신원 영역에 테마색을 쓰고, 업무 표와 폼은 흰 작업 영역으로 구분한다.

2026-11-06 개발 검증에서 React 327개, Java 단위·MVC 141개, Python 도구 62개와 타입·빌드가 통과했다. 로그인 성공 후 홈 이동, 익명·쓰기 접근 차단, 홈 표시 데이터의 범위를 확인했다. 320·375·390px 세로, 844×390 가로, 1440px PC에서 차콜·블루 합성 화면을 확인했다. 홈 메뉴와 내 정보 이동, 인사 헤더, 신청서·결재선, Esc와 초점 복귀가 포함된다. PostgreSQL 통합과 공개 서버는 이번 화면 검증 범위 밖이다.
