# 업무 화면 테마와 정보 계층

기준일: 2026-11-05 (Asia/Seoul). 사용자 요청은 기존 디자인 전면 개편과 차콜·블루 테마 전환이다.

## 화면 계약

- 기존 React 화면·URL·폼 필드·CSRF·버전·명령 ID·권한·신청/승인 효력을 유지한다.
- `ThemeSwitcher`는 `charcoal | blue`만 허용한다. 최초 기본값은 차콜이다.
- 선택값은 브라우저 `localStorage`의 `worklog-theme`에 저장한다. 저장소가 차단되어도 현재 화면에서 전환할 수 있다. 잘못된 저장값은 차콜로 처리한다.
- 루트 `data-theme`로 공통 색상 토큰만 전환한다. 권한·로그인 주체·업무 자료는 변경하지 않는다.
- 로그인·소개·업무 화면에서 같은 테마를 사용한다. 테마 선택은 키보드로 조작할 수 있다.
- 업무 메뉴 앞에 본문 건너뛰기를 제공하고 실제 main 영역으로 초점을 이동한다.

## 디자인

Hallmark Refract의 밝은 표면을 업무 앱에 맞게 해석한다. 사용자 요구에 따라 장식·광원·움직임 대신 화이트, 차콜 글자, 선과 여백을 사용한다. 블루 테마는 주요 액션·현재 선택·포커스만 파란색으로 바뀐다. 한국어 시스템 글꼴을 유지하고 외부 폰트를 요청하지 않는다.

- 공통 토큰: `frontend/src/tokens.css`. 기존 `--t-*` 이름은 호환성을 위해 유지한다.
- 기본 규칙: `frontend/src/base.css`. 공통 업무 레이아웃: `WorkspacePolish.css`.
- 본문 16px, 라벨·표·보조 정보 14px. 주요 제목 28px. 모서리 8px, 기본 컨트롤 44px.
- 사원 헤더는 사진·이름과 사실정보를 한 행에 정렬하고 구분선으로 나눈다.
- 메뉴는 기존 3단계 구조를 유지한다. 아이콘 배경·장식 상태점·과도한 그림자는 사용하지 않는다.
- 내 정보는 밑줄 탭, 읽기 전용 표, 수평 구분선을 사용한다.
- 신청은 수치 요약 행 → 조회 조건 → 목록. 작성 단계와 미리보기는 기존 상태를 유지한다.
- 결재는 전체 폭 목록 행, 상세·판단 영역은 선으로 구분한다.
- 테이블은 필요할 때 내부 스크롤한다. 페이지 전체 가로 넘침을 숨겨 결함을 감추지 않는다.

## 구현·검증 순서

1. 기존 화면 3개·15장 캡처, 기존 React 312개 테스트 통과를 기준으로 기록했다.
2. 테마 저장·복원·저장소 차단·키보드 본문 이동 테스트를 먼저 작성하고 실패를 확인한다.
3. 토큰/기본 스타일, 셸/사원/모달, 신청/결재/내정보, 인증/소개를 독립 파일로 병렬 구현한다.
4. React 회귀·타입 검사·production build, Hallmark 정적/렌더 검사, PC/모바일 양 테마 검증을 수행한다.
5. 변경 전후 자료·한계는 별도 검증 보고서에 기록한다. 실제 DB·공개 서버 검증과 합성 UI 검증을 구분한다.

추가 사진·통계·고객 후기·로고는 만들지 않는다. 기존 미추적 공통 시트 제안 문서는 변경하지 않는다.
