# WorkLog 정보 영역과 두 테마 보완

기준일: 2026-11-05. 사용자는 흰 배경에서 영역이 구분되지 않는 문제를 지적하고, 적절한 색감·내 정보 탭의 정보표·모든 모달에 일관된 개선과 공개 데모 배포를 요청했다.

## 표시 계약

- 테마 인터페이스는 기존 `charcoal | blue`, `data-theme`, `worklog-theme` 저장값을 유지한다.
- 페이지는 회청색 canvas, 작업 영역은 흰색, 그룹 제목과 표 머리글은 section, 항목명은 label 색을 사용한다. 블루는 같은 구조에 파란색 계열을 적용한다.
- 내 정보의 기존 section/DL/table 의미구조와 7탭 키보드 동작, 미등록·0·이력 값을 유지한다. 항목명14px·값16px, 모바일에서 모든 값을 표시한다.
- 사원 헤더, 신청 현황·잔여·단계·요약, 결재 목록, 상세 정보·이력에 역할에 맞는 색면을 적용한다.
- 공통 Modal의 제목·본문·푸터를 구분한다. 모든 업무 모달이 공유하며 초점 이동·Escape·미저장 확인·배경 보존은 기존 계약을 따른다.
- 기존 API·권한·DB·업무 문구를 바꾸지 않고 CSS 토큰과 스타일로 구현한다. 신규 의존성은 없다.

## 참고

[Carbon data table specifications](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/specifications)의 표 머리글·행·선택·hover별 표면 구분을 참고했다. WorkLog의 한국어 업무 화면과 기존 의미구조에 맞춰 적용하며 외부 디자인이나 데이터를 그대로 복제하지 않는다.

## 검증·배포 순서

1. 기존 계약 테스트를 먼저 실행하고 스타일 수정 후 React 전체·타입·빌드를 실행한다.
2. 두 테마의 내 정보7탭·신청/상세/관리 모달·PC/모바일·표 넘침·초점·선택 유지와 Hallmark 보존 검사를 수행한다.
3. 공개 전용 브랜치에 기존 데모 보안·AG Grid를 보존해 통합하고 공개 검증을 실행한다.
4. 기존 공개 V17에서 SQL/Java를 바꾸지 않는 UI 자산만 배포한다. 기존 서비스 상태·Caddy·DB 스키마/자료와 JAR의 비UI 항목을 전후 대조한다.

SSH는 공개22포트 차단/Tailscale 사설망 전용 구성이다. 사용자가 로컬 Tailscale 설치 없이 열린 Hostinger 콘솔로 배포하도록 선택했으므로 SSH 공개 개방·방화벽·전역 설정은 변경하지 않는다.
