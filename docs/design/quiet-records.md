# 간결한 표와 정보 화면

2026-11-06. 사용자가 제공한 세 참고 화면에서 얇은 가로선·차분한 정보 배치·간결한 모달 구성을 참고한다. 인물 사진·이름·값·레이아웃을 복제하지 않는다.

## 표시 계약

- `charcoal | blue`, 테마 저장과 기존 한국어 서체·44px 조작 영역을 유지한다.
- 페이지의 옅은 바탕과 흰 작업 영역은 유지한다. 표와 항목명의 색은 두 테마 모두 중립색으로 줄이고 선택·주요 액션에만 테마색을 집중한다.
- 목록은 옅은 중립 머리글, 흰 행, 얇은 가로선으로 구분한다. 값 정렬·정렬/필터·상태·스크롤·편집 초점은 보존한다.
- 내 정보는 밑줄 탭, 무배경 그룹 제목, 정렬된 항목명/값으로 구성한다. PC의 밀도와 모바일의 전체 정보 표시를 함께 유지한다.
- 신청/상세/계산 근거/감사 상세와 모달도 같은 규칙을 쓴다. 제목 띠·반복 세로선·중첩 테두리를 줄인다.
- 라벨14px·정보값16px, 긴 ID 줄바꿈, 숫자 정렬, 오류·미등록·미확정 안내와 키보드 초점을 유지한다.
- CSS와 표시 토큰만 변경한다. API·스키마·권한·업무 데이터·문구·라우트·컴포넌트 인터페이스는 바꾸지 않는다.

11월5일의 `workspace-surfaces.md`에서 색상 제목 띠와 라벨 격자를 지정한 부분은 이번 사용자 피드백에 따라 이 계약으로 대체한다. 흰 영역과 배경의 구분, 두 테마와 가독성 요구는 계속 유지한다.
