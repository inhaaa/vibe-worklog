# CALC-1 순수 시간 계산 엔진

[계산 명세](../rules/calculation.md)의 시간을 Java 순수 함수로 구현한다. DB 조회·인증·승인 효과·원장·결과 저장과 분리하며 외부 라이브러리를 추가하지 않는다.

`WorktimeCalculator.day(DayInput)`, `week(LocalDate,List<DayResult>,boolean)`, `month(YearMonth,List<DayResult>)`가 불변 값 객체를 반환한다. 시각은 밀리초 정본, 구간은 [시작,종료)이며 실제 확인 휴게 합집합을 한 번 공제한다. 예정 휴게를 실제 휴게로 간주하지 않는다. 실제·소정·일8시간 초과·주40시간 초과·야간·휴일은 별도 필드다. 법정 가산 최종 연장값은 null로 유지한다.

일정·캘린더·확인·법 적용 검토가 미확인되거나 대기 정정·중복·자정 통과·휴가 충돌이 있으면 REVIEW_REQUIRED 사유를 보존한다. 일별 actual null을0으로 바꾸지 않고 기간 합계에는 확인된 부분합과 미확정 건수를 함께 반환한다. 주는 월요일 시작7일이며 월 경계로 주를 자르지 않는다. 누락 날짜가 있는 기간은 정상 확정으로 표시하지 않는다.

확인은 사실/검토 개정에 결속하며 저장된 결과의 최신성은 두 개정 모두 비교한다. 입력 자료의 tenant·권한 검증과 실제 캘린더·정정·휴가 효력 조회는 호출 서비스의 책임이다. 엔진만 구현했다고 일월 현황·급여·법률 적합성·MVP 전체 완료로 표시하지 않는다.
