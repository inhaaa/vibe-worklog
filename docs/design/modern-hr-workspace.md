# WorkLog 업무 화면 재설계

- 차콜과 블루를 유지한다. 내비게이션은 잉크색 바탕과 업무별 아이콘으로 구분한다. 현재 업무와 초점은 각각 배경과 윤곽선으로 표시한다. WorkLog 로고는 PC와 모바일의 홈 링크다.
- 일반 콤보박스는 둥근 입력면과 짧은 방향 표시를 사용한다. 키보드와 모바일의 시스템 선택 동작을 유지한다.
- 홈은 낮은 환영 헤더에서 핵심 지표, 오늘 근무·최근 신청, 주간 일정으로 이어지는 단일 작업면으로 구성한다. 기존 조회 데이터와 이동 경로를 재사용한다.
- 내 정보 기본사항은 신원·입사·추가 정보를 구분한 읽기용 시트다. 7개 기록 항목은 시트에 연결된 목차에서 선택한다. PC와 모바일에서 항목과 값의 관계, 전체 정보 표시, 키보드 탐색을 유지한다.
- 근태 신청은 간결한 결재선과 신청자, 신청서 순서로 배치한다. 연차 묶음은 잔여일과 사용 기간을 함께 표시하는 단일 선택 시트에서 고른다. 시작일과 종료일(포함)은 같은 신청 기간 시트에서 선택한다. 기존 bucketId와 from/to, 미리보기·제출, 권한과 날짜 검증 계약을 유지한다.

현재 React와 CSS, 기본 HTML 입력으로 구현한다. 컴포넌트 라이브러리 도입은 공통 선택 위젯이 복잡해져 재사용 필요가 생길 때 다시 판단한다.

2026-11-06 개발 검증에서 전체 프런트엔드 테스트 331개, TypeScript 타입 검사와 Vite 빌드가 통과했다. 로컬 합성 데이터로 블루·차콜 테마를 1440·960·844·390·320px의 Chromium 화면 10조합에서 검증했다. 홈 이동, 인사기록 7개 항목과 방향키 탐색, 연차 선택, 날짜 입력과 종료일 제약, 모달 닫기 후 초점 복귀를 확인했다. 공개 데모 반영은 별도 배포 단계다.
