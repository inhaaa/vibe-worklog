# WorkLog 업무 화면 재설계

- 차콜과 블루를 유지한다. 내비게이션은 잉크색 바탕과 업무별 아이콘으로 구분한다. 현재 업무와 초점은 각각 배경과 윤곽선으로 표시한다. WorkLog 로고는 PC와 모바일의 홈 링크다.
- 일반 콤보박스는 둥근 입력면과 짧은 방향 표시를 사용한다. 키보드와 모바일의 시스템 선택 동작을 유지한다.
- 홈의 환영 영역과 출퇴근·근태 신청 바로가기는 고정한다. 예정 근무, 사용 가능 연차, 검토 중인 내 신청, 오늘 근무, 최근 내 신청, 주간 일정은 각각 편집 가능한 위젯이다. 처음에는 모두 표시하고, 편집에서 하나씩 선택하거나 모두 숨길 수 있다. 저장은 이 브라우저의 계정별 설정에 반영하며, 취소는 이전 표시를 유지한다.
- 홈 응답의 `homeWidgetScope`는 인증된 테넌트와 계정으로 만든 불투명한 환경설정 식별자다. 브라우저에는 이 식별자로 구분한 위젯 ID 목록만 저장한다. 저장소를 사용할 수 없거나 식별자가 없는 경우 화면에서 편집할 수 있다. 홈의 업무 데이터와 조회·이동 경로는 기존 계약을 사용한다.
- 내 정보의 선택 탭은 테마색 배경, 강조선, 굵은 라벨로 표시한다. 기본사항과 연락처는 섹션별 제목 아래에 라벨과 값을 배치하며, 발령과 이력은 가로 구분선으로 정리한다. 7개 기록 항목의 데이터와 키보드 탐색을 유지한다.
- 근태 신청은 간결한 결재선과 신청자, 신청서 순서로 배치한다. 연차 묶음은 잔여일과 사용 기간을 함께 표시하는 단일 선택 시트에서 고른다. 시작일과 종료일(포함)은 같은 신청 기간 시트에서 선택한다. 기존 bucketId와 from/to, 미리보기·제출, 권한과 날짜 검증 계약을 유지한다.

현재 React와 CSS, 기본 HTML 입력으로 구현한다. 컴포넌트 라이브러리 도입은 공통 선택 위젯이 복잡해져 재사용 필요가 생길 때 다시 판단한다.

2026-11-06 개발 검증에서 전체 프런트엔드 테스트 334개, 홈 인증·화면 Java 테스트 11개, TypeScript 타입 검사와 Vite 빌드가 통과했다. 로컬 합성 데이터로 블루·차콜 테마를 1440·960·844·390·320px의 Chromium 화면 10조합에서 검증했다. 위젯 편집·복원과 계정별 구분, 인사기록 7개 탭과 선택 색, 연차 선택과 날짜 검증, 모달 닫기 후 초점 복귀를 확인했다. 공개 데모 반영은 별도 배포 단계다.
