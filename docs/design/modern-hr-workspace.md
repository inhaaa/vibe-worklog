# WorkLog 업무 화면 재설계

- 차콜과 블루를 유지한다. 내비게이션은 잉크색 바탕과 업무별 아이콘으로 구분한다. 현재 업무와 초점은 각각 배경과 윤곽선으로 표시한다. WorkLog 로고는 PC와 모바일의 홈 링크다.
- 일반 콤보박스는 둥근 입력면과 짧은 방향 표시를 사용한다. 키보드와 모바일의 시스템 선택 동작을 유지한다.
- 홈의 환영 영역과 출퇴근·근태 신청 바로가기는 고정한다. 예정 근무, 사용 가능 연차, 검토 중인 내 신청, 오늘 근무, 최근 내 신청, 주간 일정은 처음에 모두 표시한다. ‘내 위젯’ 옆 톱니바퀴로 위젯 설정 모달을 열어 항목을 하나씩 선택하거나 모두 숨길 수 있다. 저장은 이 브라우저의 계정별 설정에 반영한다. 취소·닫기·Escape는 초안을 버리고, 모달을 닫으면 설정 버튼으로 초점이 돌아간다.
- 홈 응답의 `homeWidgetScope`는 인증된 테넌트와 계정으로 만든 불투명한 환경설정 식별자다. 브라우저에는 이 식별자로 구분한 위젯 ID 목록만 저장한다. 저장소를 사용할 수 없거나 식별자가 없는 경우 화면에서 편집할 수 있다. 홈의 업무 데이터와 조회·이동 경로는 기존 계약을 사용한다.
- 공통 인사 헤더는 메뉴의 선택 색을 사용하는 프로필과 흰색 인사 요약을 나란히 배치한다. 인사 요약은 생년월일·직급·직책·직무·입사일을 가는 구분선으로 나누고, 영역의 실제 너비에 따라 2·3·5열로 표시한다. 폭이 좁으면 두 영역을 위아래로 배치한다. 이름과 회사만 제공되는 화면에는 간결한 프로필을 표시한다.
- 내 정보의 선택 탭은 테마색 배경, 짧은 강조선, 굵은 라벨로 표시한다. 넓은 화면에서는 탭에 항목별 아이콘을 표시하고, 모바일은 한 줄 라벨로 배치한다. 키보드 초점은 별도의 윤곽선으로 표시한다. 기본사항과 연락처는 섹션별 제목 아래에 라벨과 값을 배치하며, 발령과 이력은 가로 구분선으로 정리한다.
- 근태 신청은 결재 정보 표, 신청자 정보, 신청 내용, 하단 요약과 동작을 한 장에 이어서 배치한다. 종일 연차와 출퇴근·휴게 정정은 같은 구성에서 유형별 입력 행을 표시한다. 연차 묶음은 잔여일과 사용 기간을 함께 표시하는 단일 선택 시트에서 고른다. 시작일과 종료일(포함)을 누르면 신청서 안에 공통 월간 달력이 열린다. 시작일은 서울 기준 오늘부터, 종료일은 시작일부터 선택할 수 있다. 시작일이 기존 종료일보다 뒤로 바뀌면 종료일 값을 유지하고 수정 안내를 표시한다. 방향키로 날짜를 탐색하고 Enter로 선택하며 Escape는 날짜 시트만 닫는다. 선택하거나 닫으면 해당 날짜 버튼으로 초점이 돌아간다. 기존 `bucketId`와 `from`·`to`, 미리보기·제출, 권한과 날짜 검증 계약을 유지한다.

React와 CSS로 구현한다. 출퇴근·휴게 정정의 근거 날짜는 기존 HTML 날짜 입력을 사용한다.

2026-11-06 후속 화면 검증에서 전체 프런트엔드 테스트 338개, TypeScript 타입 검사와 Vite 빌드가 통과했다. 로컬 합성 데이터로 블루·차콜 테마를 1440·960·844·390·375·320px의 Chromium 화면 12조합에서 검증했다. 위젯 설정 모달의 저장·취소·Escape·초점 복귀, 계정별 복원, 신청 화면을 불러올 때 모달 중복 방지, 인사기록 7개 탭의 색과 키보드 탐색을 확인했다. 공개 데모 반영은 별도 배포 단계다.

2026-11-07 공통 인사 헤더 배색 조정 후 프런트엔드 테스트 339개, 타입 검사와 빌드가 통과했다. 블루·차콜 테마에서 7가지 Chromium 화면 크기로 메뉴와 헤더의 배색, 글자 대비와 항목 배치를 확인했다. 긴 이름과 직무, 사진 표시·이니셜 대체, 관리 화면의 간결한 요약은 로컬 합성 데이터로 검증했다.
