# 월말 퇴근 누락 보완 요청 구현 계획

[업무 명세](../specs/2026-11-18-month-end-correction-followups.md)의 사원·근무일 한 건을 따라 다음 순서로 구현한다.

1. PostgreSQL에서 V29의 테넌트 격리, 열린 요청 유일성, 등록 명령 재전송과 재집계 원자성을 검증한다. 현행 담당자 권한과 기존 퇴근 누락 기준으로 등록·조회할 서비스를 연결한다.
2. 회사 월말 조회에는 표시할 행들의 활성 요청을 일괄 조회한다. 직원 홈·본인 전체 목록에 독립된 보완 사유와 해당일 정정·근무확인 링크를 연결한다. 읽기 요청에서는 상태를 쓰지 않는다.
3. 화면 테스트로 담당자의 사유 입력·중복 방지·같은 조건 재조회, 직원의 업무 상태별 이동, 빈 목록·페이지를 확인한다. 정정과 결재에는 기존 원천·승인자·테넌트 검증을 적용한다.
4. 실제 브라우저에서 서로 다른 가상 사원으로 PC와 모바일의 요청 → 정정 → 중간·최종 승인 → 재집계 → 해소를 검증한다. 최종 검증 결과를 기록하고 기능별로 커밋·푸시한다. 공개 데모 배포는 보류한다.
