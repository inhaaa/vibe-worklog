# 월 마감 점검 상세와 Excel 구현 계획

[업무 명세](../specs/2026-11-19-month-close-details-export.md)

1. 점검 항목과 기존 월말 목록 사유를 대응시키고, 신청·보완 요청 단위의 전용 조회 계약을 고정한다. 건수 일치, 월경계, 재직기간 밖, 접근 권한, 원래 조건 복귀부터 실패 테스트로 작성한다.
2. 점검과 같은 회사 범위의 실제 미처리 목록을 제공한다. PC·모바일 양수 링크와 빈 결과, 목록·상세의 복귀 경로를 연결한다. 서버와 프런트 테스트 후 첫 기능 단위로 커밋한다.
3. 마감 버전별 사원·부서 결과 보관과 기존 마감 이관을 추가한다. 담당자·테넌트 경계, 월중 부서 이동, 재개된 버전 차단과 회사 중복 제거를 자동 검증한다. 기존 OOXML 작성기를 사용해 회사·부서 합계와 사원 명세를 내보낸다.
4. 마감 화면의 범위 선택·다운로드를 연결하고 PC·모바일에서 실제 파일을 연다. 완성한 두 번째 기능을 커밋하고 해당 브랜치를 일반 Push한다.
