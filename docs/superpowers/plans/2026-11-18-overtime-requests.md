# 연장근무 구현 계획

[업무 명세](../specs/2026-11-18-overtime-requests.md)를 기준으로 각 단위의 실패 사례를 먼저 작성한다.

1. 근무일별 유효 시간코드·회사 캘린더 조회와 구간 교집합 계산을 구현한다. 135분·부분 휴게·경계·기준 변경을 검증한다.
2. 후속 Flyway에서 신청서 종류·근거·승인 효력 저장 구조를 정의하고 기존 신청·결재 엔진에 신청·철회·반려·최종 승인·전체 취소를 연결한다. 중복·재시도·고객사 격리와 순차결재를 검증한다.
3. 직원 신청·상세·취소, 담당자 기간·상태 조회 및 실제 출퇴근 대조를 내비게이션과 화면 모델에 연결한다. 기존 전용 목록의 분류를 회귀 검증한다.
4. 전용 로컬 환경에서 Java 및 React 테스트·빌드와 PC·모바일 사용 흐름을 확인한다. 검증 후 작업별 커밋을 현재 기능 브랜치에 일반 푸시하고 원격 SHA를 확인한다.
