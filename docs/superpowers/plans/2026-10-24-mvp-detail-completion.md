# MVP 상세 조회와 시각 표시 마무리 계획

## 범위와 구조

사용자의 질문 없는 후속 진행 승인 범위는 계산 근거 상세·감사 상세/페이지·서울 시각 표시다. 기존 Worktime 서비스/Mapper·트랜잭션·템플릿을 재사용한다. 새 라이브러리·새 테이블·외부 서버·배포·실제 메일은 추가하지 않는다. 실행은 기존 관리 worktree에서 진행하며 main에 검증 후 fast-forward와 일반 Push한다.

[상세 계약](../../design/worktime-results.md)을 기준으로 불변 근거와 최소 권한을 먼저 정의한다. 구현 담당과 검토 담당을 나누며 공유 파일은 계산 상세 → 감사 확장 순서로 한 명씩 수정한다. Maven·DB·Docker·Git 실행은 root가 담당한다.

## 작업 단위

- [x] 계산 상세 DTO/HTTP·안전한 당시 근거·최신성/버전 구분·월 목록 링크·공통 시각 표시 기반.
- [ ] 감사 DTO/상세·전후 안전 요약·양방향 커서 페이지·V10 인덱스·열람 감사.
- [ ] 기존 화면·새 XLSX의 서울 날짜/시각 통일, 자정/연말/밀리초/안전 구간 표시.
- [ ] 최종 전체 회귀·Docker·합성 브라우저·문서 일관성과 로컬/원격 Git 상태 확인.

각 단위는 먼저 실패 테스트를 실제 실행한 뒤 구현한다. 관련 통합 테스트와 테넌트/권한 검증, 문서 링크·UTF-8·비밀값·git diff 검토를 통과한 파일만 커밋·Push한다. 실제 실행하지 않은 검증은 완료로 쓰지 않는다.

계산 상세: 최초 null stub 실패와 누락 목록/정책 근거의 실제 RED 후 구현. 전체344개 통과 뒤 추가 누락 회귀를 포함한 관련76개(단위39·통합37) 재검증 통과. 이후 감사 단위로 진행한다.
