# 반일 잔여와 월말 확인 대상 구현 계획

[반일 잔여·일괄 등록 명세](../specs/2026-11-18-leave-balance-batch.md)와 [월말 확인 명세](../specs/2026-11-18-month-end-review.md)를 각각 독립적인 변경으로 검증한다.

1. 연차 수량과 원장. V28 마이그레이션 테스트에서 7.5 기초와 ±0.5 조정, 0.25 거부 및 기존 행 보존을 확인한다. 단건 서비스, 귀속 연도별 합계 및 단건 폼을 같은 단위로 연결한다.
2. 담당자 일괄 입력. PostgreSQL 통합 테스트와 React 테스트에서 서로 다른 두 사원의 기초·조정, 읽기 전용 미리보기, 오류 행, 묶음 버전 충돌, 재시도와 권한을 확인한 뒤 일괄 서비스와 시트를 연결한다. 직원 신청·취소 후 잔여와 원장을 대조한다.
3. 월말 목록. 기존 회사 근무현황에 담당자 전용 조회 방식을 추가한다. 월·적용일 소속·검색·사유별 후보를 판정해 페이지 단위로 가져온다. 빈 월, 월 경계, 휴무·승인 휴가·반차, 미확인·정정 대기, 테넌트·권한을 통합 테스트에 포함한다.
4. 담당자 화면과 복귀. React에서 월·조직·사번·확인 사유 필터, 사유별 상세와 페이지 복귀를 검증한다. 서버 통합·프런트 전체 회귀와 운영용 번들을 확인하고 PC·모바일의 합성 자료 시나리오를 점검한다.
5. 명세 변경과 실제 검증 결과를 기록하고 기능별 커밋을 일반 푸시한다. 공개 데모 배포는 보류한다.
