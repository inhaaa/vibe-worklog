# 선택근무제 구현 계획

기준 개발본은 월 마감 상세·Excel이 있는 `1d351fb`다. [선택근무제 명세](../specs/2026-11-20-selective-work.md)를 따른다.

| 순서 | 개발 단위 | 검증 |
| --- | --- | --- |
| 1 | 기존 근무시간코드와 요일·배정의 계약을 확장하고 V32로 불변 버전에 선택 정책 저장 | 예전 입력, 선택창·코어·표준분·혼합 편성, 개정·재조회, 기존 DB 업그레이드 |
| 2 | 단건과 일괄 일정 해석, 실근로 계산, 주·월 정산 및 본인·담당자 조회 API | 고정 지문 보존, 반차·취소·정정, 잠정 수치, 월경계, 권한 및 타사 격리 |
| 3 | 담당자 입력·미리보기·사원 배정과 직원 일정·월별 근무현황 및 월 마감에서 연결 | 설정 저장·재조회, 사원/월 전환과 빈 결과, 조회 중·오류·모바일 레이아웃 |
| 4 | 전용 로컬 DB와 실제 브라우저로 시나리오를 수행하고 서버·프런트 회귀 검증 | PC·모바일 크기에서 담당자 설정과 직원/담당자 정산 대조, 빌드 결과 기록 |
