# 회사별 휴가 운영 구현 계획

기준은 [첫 고객사 운영 PRD](../../prd.md)다. 담당자가 연 경조휴가와 개인휴가를 직원이 신청하고, 결재와 취소 뒤 직원·담당자 화면과 월 마감 파일에서 결과를 대조하는 한 업무로 구현한다.

| 범위 | 구현 계약 | 검증 사례 |
| --- | --- | --- |
| 회사 정책 | 기존 근태코드에 적용일별 회사 휴가 정책을 저장한다. 유급·무급과 연차 차감·미차감은 독립 설정이다. 종일 전용 또는 종일·반일 사용을 지정한다. 기존 초안은 담당자가 명시적으로 용도를 변경할 때 열고 기존 연차는 동일하게 사용한다. | 정책 등록·개정·사용 종료, 허용 조합과 잘못된 조합, 기존 코드와 타사 자료 보존 |
| 신청과 결재 | 대상일 기준 목록과 미리보기에서 종류·사용량·예상 차감과 기존 신청서 결재선을 보여 준다. 접수 시 정책 버전을 보존하고 중간 승인은 대기, 최종 승인 때 효력을 기록한다. 취소 최종 승인 때 원신청에 적용한 효력만 복원한다. | 잔여 묶음이 없는 직원의 미차감 휴가, 잔여 부족과 중복 신청, 팀장·실장 순차 승인, 반려·철회·취소·재시도, 미리보기 후 개정 |
| 근태와 마감 | 실제 근로, 휴가 사용량, 유급 인정시간을 구분한다. 유급 경조휴가와 무급 개인휴가는 둘 다 사용량에 포함하며 유급휴가만 정산 인정시간에 합친다. 승인 당시 이름과 정책을 사용한다. | 종일·반일, 적용일 경계, 승인·취소 전후 종류별 조회, 직원·담당자 정산과 마감 Excel, 기존 마감 버전 |

근태코드 관리·신청·집계별 회귀를 먼저 작성하고 해당 화면과 서비스를 연결한다. 마지막에 실제 브라우저의 PC·모바일 화면에서 신청부터 결과 재조회까지 확인하며 전체 Java·PostgreSQL·프런트 회귀와 빌드를 실행한다.
