# WorkLog 화면 정돈·업무 모달 구현 계획

**목표:** 조직장·권한·인사·근무 배정과 신청을 원래 화면 위에서 처리하고, 내정보·신청·사원 헤더의 시각 체계를 통일한다.

**설계:** 기존 React page envelope·서버 검증·CSRF를 유지한다. `App`은 목록의 컴포넌트와 조회 조건을 유지한 채 작업 화면을 공통 native dialog로 연다. 새 의존성·API·DB 스키마는 추가하지 않는다. 독립 URL 직접 접근은 기존 화면으로 제공한다.

## 인터페이스와 동작 계약

- `Modal({ title, children, onClose, busy?, className? })`: X·닫기·Esc, 원래 초점 복귀, 모달 내부 스크롤, 처리 중 닫기 차단. 배경 클릭은 닫지 않는다.
- `PageProps.onClose?: () => void`: 신청 작성 화면이 외부 모달에 포함됐음을 나타내며 중복 dialog를 만들지 않는다.
- 수정·신청 경로는 배경 envelope·URL·revision을 보존한다. 모달 내 재조회·검증 실패는 모달에 머문다. 저장 뒤 배경은 서버에서 갱신한다. 401/403/재인증 응답은 배경의 개인정보도 제거한다.
- 미저장 입력은 모달 닫기·뒤로가기에서 확인한다. 원래 화면의 필터·선택 탭·스크롤은 저장 전 닫기에서 보존한다.
- 기존 인디고 브랜드, 밝은 중립 표면, 명료한 제목/라벨, 4/8px 간격, 카드·정보표를 사용한다. 내정보 7탭은 모든 기존 값과 미등록/비해당 구분을 보존한다.
- 개인정보·권한·원장·계산·지원 신청 종류는 바꾸지 않는다.

## 검증 명령

`npm.cmd test -- --maxWorkers=2` 및 `npm.cmd run build`를 frontend에서 실행한다. Windows sandbox의 Node 사용자 경로 접근 제한은 동일 명령의 일반 사용자 실행으로 확인한다. 최초 기본 검증 285개 중 283개 통과, 대형 50행 DOM 테스트 2개가 병렬 자원 경합에서 5초 timeout이므로 worker 수를 줄여 재확인한다. 제품 timeout이나 테스트 제한은 임의로 늘리지 않는다.

기존 수정 중인 `DemoAccess.css`와 `2026-10-29-common-sheet-design.md`는 이번 변경에 포함하지 않는다. 공개 적용은 개발본 전체 덮어쓰기 없이 공개 보안 변경을 보존하고 전용 절차의 검증을 수행한 경우만 완료로 기록한다.
