# 근무조별 근무설정 구현 계획

[승인 명세](../specs/2026-11-18-workgroup-schedule-design.md) · 기준 커밋 `c819db1`

| 단위 | 데이터와 인터페이스 | 검증할 사용 흐름 |
| --- | --- | --- |
| 근무시간코드 | 고객사별 불변 코드·버전과 정규 및 연장 휴게 구간, 담당자 등록·개정·조회 | 09~18시, 복수 휴게, 연장 최대 135분, 비활성 및 잘못된 구간 |
| 근무조 개정 | 요일별 코드 버전을 기존 주간 일정 버전으로 발행. 날짜·기대 버전·명령 ID 및 영향 명단 확인 | 전날과 첫날, 같은 날 전출, 이후 전입, 코드 버전 고정 |
| 사원 배정 | 기존 고정 배정과 조 배정을 같은 근무일 기준으로 해석. 단건·일괄 배정 및 최초 발령에서 동일 계약 사용 | 재직기간, 이전 이력·미래 예약 보존, 경합·재시도, 일괄 실패 원자성 |
| 사용자 화면과 소비처 | 근무 설정 세 탭, 직원 본인 일정, 출퇴근·휴가·집계가 해석한 동일 일정 | 담당자 등록→미리보기→배정→개정, 직원 날짜별 재조회. PC·모바일 브라우저와 권한 회귀 |

각 단위는 기대 결과를 테스트로 먼저 작성한다. 전용 로컬 DB에 마이그레이션을 적용하고 단위·통합·프런트엔드·브라우저 결과를 확인한 뒤 작업별로 커밋한다.
