# 일상 근태에서 회사 월 마감까지

담당자가 회사 근무현황에서 누락을 찾는다. 직원이 신청하고, 결재자는 정정 대상일·제안 시각 및 휴가 종류·기간을 확인하고 승인한다. 대기 중에는 승인 효력이 생기지 않는다. 담당자는 미처리 요인을 확인하고 재집계한 뒤, 서울 기준 다음 달에 전체 확인 대상·결재 대기·미해소 보완이 모두 0인 것을 다시 점검해 마감한다.

직원은 본인 근무 결과에서 실근로·사용 휴가·유급휴가 인정시간을 각각 확인한다. 담당자가 내려받은 회사 전체와 두 부서의 파일을 열어 사번별 합계와 부서별 명세를 대조한다. 회사 전체는 3명, 재직 4일, 실근로 발생 2일·11.5시간, 사용 휴가 1일, 유급휴가 인정 8시간이다.

## 저장과 파일 계약

- 마감 가능 여부를 재검사하는 트랜잭션에서 기존 일 계산기의 유급휴가 인정 밀리초를 근무일 당시 사원·소속과 함께 고정한다. 고정 근무 종일휴가처럼 일 결과를 별도로 저장할 필요가 없는 날과 선택근무의 하루 표준시간도 같은 계산 근거를 사용한다.
- 새 마감 파일의 합계, 부서별 합계, 사원·부서별 명세 끝에 숫자 열 **유급휴가 인정시간(시간)**을 추가한다. 실근로시간과 사용 휴가일수는 기존 단위를 유지한다. 인정 근거가 미확정이면 합계에도 미확정을 전달한다.
- 기존 마감의 자료와 파일 형식은 보존한다. 새 마감에서 유급휴가가 0시간이면 숫자 0을 기록한다. 재개 후 다시 마감하면 그때의 결과를 새 버전에 기록한다. 기존 담당자 권한, 테넌트 격리, 마감 버전 확인과 다운로드 감사를 사용한다.

## 구현·검증 순서

1. 마감 Excel 회귀 테스트에 새 숫자 열, 기존 파일, 확정된 0과 미확정, 부서 이동·분리와 불변성을 명시한다. 기존 구현에서 실패를 확인한 뒤 마감 저장과 파일 생성을 연결한다.
2. 전용 PostgreSQL에 합성 근태·근무 기준과 사용자만 준비한다. PC Chrome과 390px 모바일 터치 환경에서 로그인해 신청, 승인, 재집계, 마감을 수행하고 직원 화면에 표시된 결과를 수집한다.
3. 두 환경의 브라우저에서 회사 및 각 부서 파일을 실제로 내려받는다. 같은 마감본을 다른 기기에서도 받아 대조한다. 검산기는 각 파일의 월·버전·범위, 숫자 셀, 직원과 근무일 당시 소속, 부서·회사 합계를 화면 관측값과 고정 사례 양쪽으로 확인한다.
