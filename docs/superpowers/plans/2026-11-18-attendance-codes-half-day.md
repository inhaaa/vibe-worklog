# 근태코드 간소화·반차 구현 계획

[업무 명세](../specs/2026-11-18-attendance-codes-half-day.md)에 맞춰 기존 근태 정책·휴가 신청·결재·원장 경로를 확장한다. 검증은 합성 자료가 있는 전용 로컬 환경에서 수행한다.

1. **근태코드 전환**. 기존 코드 충돌·신규 고객사·긴 코드 검색의 실패 테스트를 작성한다. Flyway V26, 근태코드 등록 및 관리 조회, 휴가현황 필터를 연결한다. 기존 정책 식별자와 이미 제출된 신청을 대조한다.
2. **반차 저장·결재**. 같은 반일과 종일의 중복, 반대 구간 신청, 잔여 부족, 두 단계 결재 및 취소를 먼저 테스트한다. V27에서 신청 구분과 일별 수량·원장·집계의 반일 표현을 추가한다. 기존 업무 서비스에서 제출·승인·취소 시 동일한 원장 규칙을 적용한다.
3. **읽기와 집계**. 연간 현황·예상량·잔여, 회사·담당자 조회, 홈·캘린더와 근로시간 집계의 소수 손실을 테스트한다. 날짜별 승인 효과와 기존 저장 결과를 구분하고 출퇴근 누락 판단을 확인한다.
4. **직원·담당자 화면**. 신청서에 연차 단위와 한 날짜 입력을 추가하고 예상 차감, 오류, 결재·취소 상세, 원신청 이력 및 달력 합계를 검증한다. 기존 종일·정정 화면의 회귀 테스트를 함께 수행한다.
5. **통합 검증과 전달**. Maven·프런트엔드 회귀와 빌드, PC·모바일 신청·결재·취소·조회 검증을 수행한다. 결과를 기록하고 작업 단위로 커밋·일반 푸시한다. 공개 데모 배포는 보류한다.
