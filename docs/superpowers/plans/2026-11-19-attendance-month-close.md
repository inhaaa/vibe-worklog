# 회사 근태 월 마감·재개 구현 계획

[업무 명세](../specs/2026-11-19-attendance-month-close.md)를 직전 월말 일괄 재집계 `90ca221` 위에 구현한다.

1. V30에 월별 상태 전환 이력과 RLS를 정의한다. 전체 사원·일의 점검은 기존 월말 판정을 공유하고, 최신 상태 조회·마감·재개·동시 명령·권한 회수·재전송을 전용 PostgreSQL로 검증한다.
2. 기존 근태 변경 명령에서 테넌트 잠금 획득 뒤 영향을 받는 날짜를 검사한다. 월말·월초가 같은 주인 경우, 복수 월에 걸치는 신청, 소급 캘린더와 사원 재직일 변경, 기존 확정 결과의 최신성을 회귀 테스트한다.
3. 월말 화면에서 담당자가 회사 전체 점검·마감·재개·처리 이력을 사용할 수 있게 한다. 당월, 미해결 건, 버전 충돌, 조회 실패·재시도, 권한 회수, 월 전환을 React로 검증한다.
4. PC와 모바일 크기의 로컬 Chrome에서 점검 차단·해소·마감·변경 차단·사유 재개·재마감을 확인하고 실제 DB 이력과 대조한다. Java·React 테스트, 프런트 빌드와 Git 변경을 검증해 작업 단위로 커밋·푸시한다. 공개 데모 배포는 계속 보류한다.
