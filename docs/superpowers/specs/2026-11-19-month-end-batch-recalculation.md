# 월말 확인 대상 일괄 재집계

담당자는 회사 근무현황의 **월말 확인 대상**에서 여러 사원·날짜를 선택한다. 재집계 전에 대상과 영향을 받는 주를 확인하고, 처리 후 같은 화면에서 해소된 건과 남은 확인 사유를 읽는다. 인접 주에 이미 마감한 날짜가 있으면 열린 날짜만 재집계한다. 지난 달의 마감·재개 절차는 [회사 근태 월 마감과 재개](2026-11-19-attendance-month-close.md)를 따른다. 급여 확정은 후속 업무다.

## 담당자 흐름

1. 조회 월·당시 조직·사번 또는 이름·확인 사유로 검색한다. 현재 페이지의 행을 개별 선택하거나 ‘현재 페이지 전체 선택’으로 고른다. 한 페이지는 최대 50행이며 조회 조건이나 페이지를 바꾸면 새로 선택한다.
2. ‘선택 재집계’의 미리보기에서 선택한 사원·날짜·현재 사유와 실제 계산할 월~일 범위를 본다. 같은 사원의 같은 주는 한 번만 계산한다. 주가 조회 월을 넘어가면 인접 월의 열린 날짜까지 계산 범위에 표시한다. 미리보기는 읽기 전용이다.
3. 1~500자의 재집계 사유를 한 줄로 적고 한 번 실행한다. 사유 입력 오류는 같은 미리보기에서 수정할 수 있다. 선택한 날짜의 근거 또는 결과가 미리보기 이후 달라졌거나, 현재 목록에서 대상이 바뀌었으면 전체를 다시 미리본다.
4. 실행 결과는 선택한 날짜별로 사번·이름·근무일, 실근로, 해소 또는 남은 확인 사유와 일 결과 상세를 제공한다. 정정 대기와 미확인 휴게·출퇴근은 실근로 미확정으로 남고, 근거가 있는 0시간은 0으로 표시한다. 담당자는 같은 조회 조건과 페이지로 갱신한 목록에서 남은 업무를 이어간다. 보완 요청은 기존 해소 기준을 따른다.

## HTTP와 일관성

| 요청 | 보낸 값 | 결과 |
| --- | --- | --- |
| `POST /admin/calculations/month-end/preview` | `month, organizationId, q, reason, page, rows[{employeeId, workDate}]` | `{previewToken, weekCount, rows[{employeeId, employeeNo, employeeName, workDate, weekStart, weekEnd, reasons}]}` |
| `POST /admin/calculations/month-end` | 같은 조회·선택과 `previewToken, calculationReason, commandId` | `{batchId, weekCount, rows[{employeeId, employeeNo, employeeName, workDate, resultId, actualWorkMillis, reasons}]}` |

- 인증된 테넌트의 현재 근태 담당자에게만 두 경로를 허용하고 CSRF를 적용한다. 서울 기준 과거의 재직일, 요청한 회사 월말 목록의 실제 페이지에 있는 고유한 사원·날짜 1~50건만 허용한다. 다른 회사 식별자나 화면 밖의 행을 섞으면 어떤 사원의 결과도 쓰지 않는다.
- 미리보기 식별값은 대상·조회 조건·최신 일 결과와 계산 근거 및 개정을 반영한다. 실행 때 현재 권한과 근거를 다시 검사한다. 사원·주 단위로 기존 일·주 재집계를 실행해 원천과 승인 이력을 보존하고 새 일 결과를 남긴다. 선택하지 않은 날짜라도 같은 주에 포함되면 기존 주 계산 규칙을 적용한다.
- 선택 전체를 한 트랜잭션으로 실행한다. 실패 시 일 결과·보완 해소·감사를 함께 되돌린다. 동일 사용자의 같은 명령·내용 재전송은 최초 처리 결과를 반환한다. 다른 내용으로 같은 명령을 재사용하면 충돌로 응답한다. 최초 결과에는 선택한 행만 포함한다. 결과의 `reasons`는 재집계 후에도 남은 월말 사유이며 빈 배열은 해소를 뜻한다.
- 업무 입력 오류는 422로 안내한다. 선택한 날짜가 현재 페이지에서 빠지거나 계산 근거가 달라지면 409로 응답하고 새 미리보기를 제공한다. 실행 응답을 받지 못하면 같은 명령으로 결과를 다시 요청한다.
- 재집계가 성공하면 일 결과를 바로 표시하고 같은 조건으로 목록을 갱신한다. 갱신 중이거나 실패한 동안은 이전 목록을 숨긴다. 담당자는 결과를 열람하면서 목록 조회만 다시 시도할 수 있다.
