# 월 마감 미처리 목록과 마감 결과 Excel

2026-11-19 · 인사·근태 담당자 · [기존 월 마감](2026-11-19-attendance-month-close.md)

## 1. 점검에서 미처리 건으로 이동

담당자가 회사 근무현황의 월말 확인 대상에서 조회 월을 적용하고 회사 전체 마감 점검을 실행한다. 양수인 미처리 수치를 선택하면 같은 월과 같은 집계 기준으로 해당 목록 첫 페이지를 연다. 원래 화면의 부서·검색·사유·페이지는 복귀용으로 보관한다. 점검과 대상 목록 사이에 다른 담당자가 처리하면 새 조회 결과를 보여준다.

| 점검 항목 | 목록 기준 | 한 건의 단위 |
| --- | --- | --- |
| 전체 확인 대상, 미산정, 재집계 필요, 미확정, 대기 정정 | 기존 월말 목록의 ALL, UNCALCULATED, STALE, UNCONFIRMED, PENDING_CORRECTION | 사원과 근무일의 조합 |
| 결재 대기 신청 | 신청 기간이 해당 월과 겹치고 상태가 PENDING인 모든 신청서 | 신청서 한 건 |
| 미해소 보완 요청 | 해당 월의 근무일에 등록된 미해소 보완 요청 | 요청 한 건 |

같은 날의 원인이 두 가지면 사유별 목록에 각각 나타나고 전체에서는 한 번 센다. 회사 전체 수치에 진입할 때 현재 부서·사번 검색 조건을 풀고 오늘 이후 날짜는 기존 점검 기준을 따른다. 월경계에 걸친 신청과 퇴직·재직기간 밖 보완 요청도 원래 점검과 같은 조건을 쓴다. 재직 사원 수와 0건은 일반 텍스트로 표시한다.

전용 목록 URL은 /company/attendance 의 view=close-blockers, month, kind, page를 사용한다. 조회 API는 GET /admin/attendance/month-close/blockers 이며 kind는 PENDING_REQUEST 또는 OPEN_FOLLOW_UP이다. 페이지당 50건, 결정적인 정렬, 전체 건수와 다음 페이지 여부를 제공한다. 상세에서 목록으로, 목록에서 원래 월말 조건으로 돌아올 수 있어야 한다. 복귀 주소는 허용된 내부 업무 경로와 파라미터만 받는다. PC에서는 표, 모바일에서는 항목과 대상 사원을 구별할 수 있는 화면을 제공한다.

## 2. 회사·부서별 마감 결과 Excel

담당자가 마감 완료된 월을 열고 **회사 전체**, **부서**, 또는 해당하는 경우 **소속 미등록**을 선택해 .xlsx 파일을 받는다. 부서는 근무일 당시 유효한 배정으로 결정한다. 이동 당일부터 새 부서에 합산하고 입·퇴사일은 포함한다. 부서 선택에는 그 달 마감 자료에 실제 등장하는 부서만 제공한다.

- 파일에 대상 월, 마감 버전, 마감자, 서울 기준 마감 시각, 범위와 자료 기준을 표시한다.
- 범위 합계, 부서별 합계, 사원·부서별 명세를 제공한다. 지표는 재직 사원 수, 재직일수(달력일), 실근로 발생 일수, 실근로시간(시간), 효력이 있는 휴가 사용일수(0.5일 포함)다. 회사 사원 수는 부서를 이동한 사원도 한 명으로 센다. 미확정 실근로를 0으로 표시하지 않는다.
- 새 마감에서는 마감 이력과 결과를 같은 트랜잭션에 보관한다. 이후 인사정보 수정과 부서명 변경에도 동일 버전 파일 내용이 유지된다. 기능 도입 전에 이미 마감된 월은 현재 유효한 마감 버전만 이관하고 파일에 **기존 마감 · 이관 시점 기준**을 표시한다.
- GET /admin/attendance/month-close/export-options 와 /export 는 월과 화면의 마감 버전을 받는다. 파일 범위는 COMPANY, DEPARTMENT(organizationId 필수), UNASSIGNED다. 열려 있거나 버전이 달라지면 409, 해당 회사 마감에 없는 부서는 404로 응답한다. 재개 후 재마감한 월은 새 버전에서 받을 수 있다.
- 파일에는 합산에 필요한 사번·성명·소속과 결과만 담는다. 텍스트는 수식으로 실행되지 않는 셀로, 일수와 시간은 합산할 수 있는 숫자 셀로 제공한다. 모든 조회와 다운로드는 인증된 회사의 근태 담당자 권한과 RLS를 적용한다.

## 인수 기준

PC와 모바일에서 양수 건수 선택 → 목록·상세 → 원래 조회 조건 복귀를 확인한다. 두 기기에서 회사·부서 범위를 선택하고 실제 내려받은 파일의 대상 월·마감 버전·범위·값을 확인한다. 자동 테스트는 월경계, 복수 원인, 부서 이동, 반차, 미배정, 권한과 테넌트, 재개·재마감, 기존 버전의 이관을 다룬다.
