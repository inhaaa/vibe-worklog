# 공통 시트 셀 직접 편집 개선

기준: 2026-10-29, Asia/Seoul. 사용자는 상시 입력 박스를 없애고 IBSheet처럼 셀을 클릭해 편집하는 업무 UX, 단위별 커밋·Push와 공개 배포를 요청했다. 앞선 공통 시트 설계를 이 요청에 맞게 수정한다.

## 선택과 범위

설치된 AG Grid Community의 셀 편집 수명주기를 사용한다. CSS로 상시 입력 박스만 감추면 읽기/편집 구분과 Esc 복원이 불명확하다. 별도 그리드 교체는 기존 저장·권한 계약에 비해 변경 범위가 크므로 하지 않는다.

- 평소에는 텍스트와 선택값의 한글 명칭을 표시한다. 빈값은 `—`로 구분한다.
- 셀 클릭·Enter·F2로 해당 셀만 편집한다. 선택 checkbox는 한 번 클릭으로 토글한다.
- 방향키는 셀 탐색, Tab/Shift+Tab은 다음/이전 편집 셀, Enter/Shift+Enter는 확정 후 아래/위 행으로 이동한다. Esc는 현재 셀의 편집 시작값을 복원한다. 한글 조합 중 Enter는 입력 확정에 사용한다.
- 저장 전 변경 표시는 유지하며, 취소는 전체 초안을 조회값으로 되돌린다. 저장된 코드·사번과 보호 필드는 텍스트로 표시하고 편집을 차단한다.
- 조직·사원·결재선·공통코드 그룹/상세·근태코드의 입력 열에 적용한다. 조회 시트·링크·상태·checkbox는 기존 렌더러를 유지한다.

## 인터페이스와 데이터 흐름

`sheetEditorColumn<T>(column: ColDef<T>, field: (row: T, index: number) => SheetEditorField)`를 추가한다. `SheetEditorField`는 `value`, `label`, `onChange`, 선택 옵션과 기존 필수/길이/최솟값/step/읽기전용/비활성/변경/오류 속성을 제공한다. 선택 옵션은 원시값·표시명 쌍으로 유지한다.

페이지가 계속 초안과 commandId를 소유한다. 입력마다 페이지의 기존 `update(clientRowId, field, value)`를 호출하며 Grid는 원본 row를 직접 변경하지 않는다. 편집 중 저장·다른 페이지 이동에서도 최신 초안과 미저장 보호가 적용되어야 한다. `leftOn=null`, 숫자 빈값 `''`, 조직장 방식의 지정 사원 초기화와 근태정책 적용일 보정은 유지한다.

`WorklogSheetHandle.validate(): boolean`으로 비편집 셀까지 기존 필수/최솟값/길이/step 검사를 수행한다. 실패하면 공통 오류 요약과 오류 셀을 표시하고 해당 셀을 연다. 서버422 오류·409 명시 확인·503 같은 명령 재시도·50행·숨은 선택/변경은 유지한다.

## 표시와 검증

입력기의 테두리는 활성 셀에만 둔다. 읽기전용은 연한 배경, 선택 셀은 파란 외곽선, 변경·오류는 기존 공통 상태로 구분한다. 모바일 내부 가로 스크롤·식별 열 pin 해제를 유지한다. 추가 의존성·API·DB 변경 없이 CSP `self`를 보존한다.

테스트는 평소 input 부재, 클릭/F2 편집, 즉시 초안 반영과 저장 payload, Esc 복원, Tab/Enter/IME, 보호 필드, 필수 검증, 옵션 원시값, 정렬/필터 후 stable ID,409/422/503 회귀를 확인한다. 실제 PC/390px에서 박스 없는 표시·선택·편집·스크롤·콘솔을 확인한다.

공개 배포는 기존 `/srv/worklog`·`worklog-demo` 경계를 따른다. 현재 공개 기록V13과 개발V14의 차이를 통합하고 전용 백업·독립 복원·마이그레이션을 거쳐야 한다. 서버 관리 연결은 현재 미준비이며 사용자에게 Hostinger Webconsole 연결을 요청했다. 접속 불가 상태를 배포 완료로 표시하지 않는다.
