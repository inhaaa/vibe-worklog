# 공통 시트 정렬·한 줄 표시 (2026-11-01)

사용자가 헤더 정렬 통일, 숫자 우측/짧은 값 중앙/문장·4~5단어 이상 좌측과 한 행 한 줄을 지시했다. 기존 시트의 자율 적용·검증·단위별 Commit/Push 승인 범위로 진행한다.

- 헤더는 선택/숫자/텍스트 열 모두 중앙 정렬한다.
- 실제 number, 숫자 편집 필드와 기존 수량/시간 숫자 열은 우측이다. 문자열 식별 코드/사번은 임의로 수량으로 파싱하지 않는다.
- 화면에 표시되는 텍스트를 기준으로 공백 분리4어절 이상 또는 문장 끝 부호/줄바꿈이 있는 값은 좌측, 나머지 짧은 이름/날짜/상태/코드는 중앙이다. 선택 필드는 원시 코드 대신 표시 라벨을 사용한다.
- 기본 행40px를 사용한다. 페이지의64/80/112px 예외와 wrapText/autoHeight를 제거하고 공통 모듈에서 줄바꿈/자동 높이를 막는다.
- 복합 셀의 기존 메모·상태·상세 링크는 한 줄로 이어 표시한다. 긴 값은 말줄임·title로 확인하며 값 자체나 저장 payload는 자르지 않는다.
- 기존 ColDef/편집/선택/오류/409·422 계약과 모바일 가로 스크롤을 유지한다. 새 라이브러리·서버·DB·설정 변경은 없다.
- 실제 그리드의 숫자/짧은 값/4어절 경계/문장/표시 라벨·복합 셀·값 변경 회귀를 먼저 실패시키고 구현한다. 전체 프론트 테스트·타입/빌드와 로컬 PC/모바일 실제 화면으로 검증한다.
