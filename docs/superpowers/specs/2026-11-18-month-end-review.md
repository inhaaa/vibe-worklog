# 회사 근무현황의 월말 확인 대상

근태 담당자는 회사 근무현황 > 월말 확인 대상에서 조회 월, 근무일 당시 조직, 사번·이름, 확인 사유를 골라 확인할 사원·근무일을 찾는다. 서울 기준 기본값은 이번 달이며 현재 월은 어제까지 조회한다. 미래 근무일과 입사 전·마지막 재직일 이후 날짜를 대상에서 제외한다.

| 확인 사유 | 목록과 연결 |
| --- | --- |
| 미산정 | 점검할 근무일에 저장된 일 결과가 없다. 사원·월의 집계 화면에서 산정할 수 있다. |
| 재집계 필요 | 저장된 결과가 최신 입력이나 검토 기준을 반영하지 않는다. 기존 집계·계산 근거로 연결한다. |
| 근무 확인 필요 | 실제 출퇴근·휴게 또는 근로 근거가 부족해 실근로시간을 확정할 수 없다. 기존 일 결과와 확인 근거를 조회한다. |
| 정정 결재 대기 | 해당 근무일의 대기 중인 정정 신청이 있다. 해당 신청 상세로 연결한다. |

사원·날짜 한 행에 해당 사유를 함께 표시한다. 승인 종일휴가 및 근거가 갖춰진 휴일·비근무일에 실근로가 없는 정상일은 건너뛴다. 승인 반차일의 나머지 근무, 휴일에 실제 기록이나 대기 정정이 있는 경우는 실제 근거로 판단한다. 정상일로 바뀌었더라도 이전 기준의 저장 결과가 있으면 재집계 대상으로 보인다. 진행 중인 [퇴근 누락 보완 요청](2026-11-18-month-end-correction-followups.md)이 있는 날은 첫 일 결과가 저장될 때까지 미산정 목록에도 남긴다. 기존의 원천, 유효한 정정, 승인된 휴가 및 집계 최신성 판정을 사용한다. 해당 사유·소속을 먼저 적용하고 근무일 내림차순, 같은 날은 사번 순으로 50행씩 표시한다. 월·조직·사유·검색어·페이지는 상세에서 돌아올 때 복원한다.

조회 시 원천 기록이나 집계를 변경하지 않는다. 담당자만 본인 테넌트 내에서 열 수 있다. 대표는 기존 월별 읽기 범위를 사용한다. 이 화면은 월말 점검 목록이며 마감 잠금·급여 확정은 별도다.
