## 화면과 직접 체험

결재 대기/본인 처리 완료를 현재 메뉴와 같은 인디고 카드로 구성했다. 대상자·기간/일수·사유·지정 담당·상태/효력을 한 카드에서 확인하고 상세의 승인/반려 검토와 실제 처리 이력으로 이어진다. 기존 공통 사원 헤더에는 탭을 추가하지 않았다. 페이지 범위 건수를 전체 건수로 표시하지 않으며 실제 서버 권한이 있을 때만 결정 폼을 제공한다.

[공개 데모](https://worklog.inhaaa.com/demo)의 **데모로 입장 → 내 업무 / 휴가·신청 / 내 근태현황·신청 → 신청 → 제출 전 확인 → 제출**로 신청한다. 상단 **계정 전환 → 승인자로 입장 → 결재 대기함 → 신청 검토 → 검토 사유 → 승인하기**로 처리한다. **내가 처리한 결재**와 신청자로 다시 전환한 본인 목록에서 승인 결과를 확인한다.

신청자·담당자는 기존 admin 사원, 승인자는 기존 DEMO-001 ‘가상 사원 하나’의 별도 계정이다. 신청자 EMPLOYEE+ATTENDANCE_ADMIN, 승인자 EMPLOYEE+APPROVER의 정확한 역할만 허용한다. 선택 화면 GET은 인증을 바꾸지 않으며 두 버튼 모두 기존 CSRF POST 로그인·실제 DB 해시·세션 회전을 사용한다. 새 서버 관리자 권한은 만들지 않았다.
