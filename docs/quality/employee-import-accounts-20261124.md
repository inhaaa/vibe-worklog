## 확인 중 고친 것

- **조직코드 안내**: 조직이 많으면 코드 목록이 한 문단으로 화면을 덮었다. 개수를 보여 주는 접힘 영역 안의 표로 바꿨다(`5c6a6dd`).

## 남은 점

- 저장 뒤에도 '등록 사유' 칸에 입력한 사유가 남는다. 다음 등록 때 지우고 쓰면 되지만 비우는 편이 낫다.
- 등록 직원의 근무조 배정·연차 잔여 입력은 기존 화면에서 이어서 한다(설계 범위 밖). 배정 전에는 홈에 "근무 일정 미배정"으로 보인다.
- 실행하지 못한 검증: 프로젝트 고정 이미지(XML·LLVM 제거판) 위의 테스트와 개통 브라우저 시나리오, 공개 데모 배포, 실제 메일.
