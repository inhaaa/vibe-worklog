- 운영 중 확보한 첫 백업을 독립 DB에 복원하고 V30까지 적용했다. WorkLog 앱만 정지한 뒤 최신 백업을 두 번째 독립 DB에 복원해 대조했다. 운영 전환 후 기존 49개 업무 테이블의 자료, 신규 신청서 기본값, 근태코드 변환, 기존 권한과 테넌트 접근 정책을 검사했다. 두 복원 DB의 연결 차단 상태도 확인했다. [보존 검증 코드](../../deploy/worklog/verify_v30_data.py)
- 테스트에 사용한 JAR와 서버의 앱·마이그레이션 이미지에서 각각 880개 파일을 대조했다. V25 SQL, 기본 스타일시트, 고지·라이선스 2개, Maven POM은 Linux의 LF를 Windows 정본의 CRLF로 되돌려 원본 바이트와 대조했다. 나머지 875개의 원본 바이트가 일치했다. [정본 파일별 해시](evidence/2026-11-19-month-close-jar.json)
