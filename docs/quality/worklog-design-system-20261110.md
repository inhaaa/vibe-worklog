### 계획과 달라진 점

- **자산 계약 테스트:** `sheetAssets.test.ts`의 첫 테스트에도 `--ag-row-height:40px` 확인이 있었다. 계획에 빠져 있어 함께 38px로 고쳤다.
- **회사 현황 테스트 도우미:** `IdentityPages.test.tsx`의 도우미는 모든 시트에 행이 생길 때까지 기다렸다. 빈 목록도 시트로 그리게 바꾸면서 빈 안내(`.ag-overlay-no-rows-center`)도 기다리게 고쳤다.
- **조회 조건 바 입력 폭:** legacy 규칙 `#tna-app .t-input{flex:1}` 때문에 입력이 바 전체로 늘어났다. `flex: none`과 200px 폭을 주었다(계획 180px). 페이지 오류 안내와 시트 머리가 붙어 있어 12px 간격도 더했다.
- **시트 높이:** 계획의 "행 수 × 행 높이 + 40" 고정 높이에서는, 열이 넘칠 때 겹침 스크롤 막대가 마지막 행을 가렸다. 겹침 스크롤 막대는 헤드리스 Chrome, macOS 기본 설정, 터치 기기에서 쓰인다. 공통코드는 1440px에서도 고정 열 기본 폭(200px) 때문에 10px 넘친다.
  - 바꾼 내용: 행이 480px 안에 들어오면 AG Grid `autoHeight`로 내용 높이에 맞춘다. 겹침 스크롤 막대는 열이 넘칠 때만 한 줄을 차지하게 했다.
  - 회귀 테스트를 더했다.
  - 이전 고정 높이에는 24px 여유가 있어 같은 넘침이 드러나지 않았다.
- **동작 확인 스크립트:** 편집한 화면에서 다른 합성 화면으로 이동하면 미저장 보호 확인 창이 뜬다. `sheet-check.mjs`가 이 창을 수락하고 종류(`beforeunload`)를 기록하도록 고쳤다.
