### 계획과 달라진 점

- **계약 테스트 파일 형식:** 계약 테스트를 `.test.js`로 작성했다(`cssLayers.test.js`, `design/tokens.test.js`). tsconfig에 node 타입이 없어 `.ts` 테스트의 `node:fs` import가 `tsc` 단계에서 TS2591로 실패했다. `viteProxy.test.js`와 같은 관례를 따랐다.
- **기본 컨트롤 규칙의 범위:** 처음 적용했을 때 층 없는 일반 규칙이 legacy 층의 부품별 변형까지 이겼다. 그 결과 다음 세 곳의 모양이 깨졌다.
  - 신청서의 기간 선택 상자(`t-request-period-trigger`)
  - "유형 변경" 텍스트 버튼(`t-request-text-button`)
  - 캘린더 ⋯ 버튼(`t-attendance-more`)

  그래서 기본 컨트롤 규칙에 `:not([class*=" t-"])`를 붙여 부품 클래스가 없는 컨트롤에만 적용했다. 다시 캡처해 세 곳이 원래 모양으로 돌아온 것을 확인했다.
- **상단바 버튼 높이:** "사번 변경"(부품 변형이라 legacy 44px)과 "로그아웃"의 높이가 달라, `shell.css`에서 상단바 버튼을 30px로 맞췄다. 모바일·터치에서는 44px이다.
- **동작 확인 방법:** 모바일 메뉴와 도움말은 브라우저 창 수동 확인 대신 헤드리스 확인 스크립트(`menu-check.mjs`, `help-check.mjs`)로 검증했다.

### 계획과 달라진 점

- **자산 계약 테스트:** `sheetAssets.test.ts`의 첫 테스트에도 `--ag-row-height:40px` 확인이 있었다. 계획에 빠져 있어 함께 38px로 고쳤다.
- **회사 현황 테스트 도우미:** `IdentityPages.test.tsx`의 도우미는 모든 시트에 행이 생길 때까지 기다렸다. 빈 목록도 시트로 그리게 바꾸면서 빈 안내(`.ag-overlay-no-rows-center`)도 기다리게 고쳤다.
- **조회 조건 바 입력 폭:** legacy 규칙 `#tna-app .t-input{flex:1}` 때문에 입력이 바 전체로 늘어났다. `flex: none`과 200px 폭을 주었다(계획 180px). 페이지 오류 안내와 시트 머리가 붙어 있어 12px 간격도 더했다.
- **시트 높이:** 계획의 "행 수 × 행 높이 + 40" 고정 높이에서는, 열이 넘칠 때 겹침 스크롤 막대가 마지막 행을 가렸다. 겹침 스크롤 막대는 헤드리스 Chrome, macOS 기본 설정, 터치 기기에서 쓰인다. 공통코드는 1440px에서도 고정 열 기본 폭(200px) 때문에 10px 넘친다.
  - 바꾼 내용: 행이 480px 안에 들어오면 AG Grid `autoHeight`로 내용 높이에 맞춘다. 겹침 스크롤 막대는 열이 넘칠 때만 한 줄을 차지하게 했다.
  - 회귀 테스트를 더했다.
  - 이전 고정 높이에는 24px 여유가 있어 같은 넘침이 드러나지 않았다.
- **동작 확인 스크립트:** 편집한 화면에서 다른 합성 화면으로 이동하면 미저장 보호 확인 창이 뜬다. `sheet-check.mjs`가 이 창을 수락하고 종류(`beforeunload`)를 기록하도록 고쳤다.

### 다음 단계로 넘긴 것

- **제목 없이 건수만 표시하는 시트 11곳:** 바깥 제목과 시트 머리를 3~5단계에서 정리한다. 소속 이력, 조직장 이력, 승인자 배정 이력, 근무 배정 이력, 일정 버전, 출퇴근 원천 기록, 최근 내 신청, 신청 목록 fragment가 여기에 들어간다.
- **조직도 트리 패널:** 5단계에서 옮긴다. 오른쪽 직원 표는 이번에 옮겼다.
- **도달하지 않는 목록 두 화면:** `AdminPages`의 `EmployeesPage`·`OrganizationsPage`는 서버가 시트 모델을 항상 보내 도달하지 않는다. 바꾸지 않고 기록만 한다.
- **legacy 부품 변형 14개:** 시트에 해당하는 변형은 없었다. 3~5단계 계획을 그대로 따른다.
- **AG Grid 필터 창:** 입력 초점 모양(quartz 기본 둥근 테두리)이 새 초점 선과 다르다. 5단계 정리 후보다.
- **고정 열 폭:** 고정한 코드 열이 AG Grid 기본 폭 200px을 쓴다. 열이 많은 시트는 가로 스크롤 줄이 생긴다. 열 폭 조정은 이번 범위가 아니다.
- **사원 헤더 카드:** 화면 위 큰 사원 헤더 카드는 4단계에서 한 줄 맥락 줄로 바꾼다.
