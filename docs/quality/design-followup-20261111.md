# 문서형 화면·업무 화면 추가 통합 검증

기준일: 2026-11-11, Asia/Seoul. `main`의 `5ed6be0` 이후 추가 작업을 확인해 Claude의 `16c102a..a65111c91218669b9d3a7d49d98380f9cde46eb3` 26개 완료 커밋을 별도 일반 제품·공개 작업트리에 통합했다. 통합 검증 당시 공개 기준은 `cc796c5`였으며 새 공개 배포는 아직 실행하지 않았다. 이후 `main`의 `7eb2bb0`을 공개 보안과 통합한 `58f8159`의 [실제 배포 결과](public-design-followup-deploy-20261111.md)를 별도로 기록했다.

## 범위와 보존

- 공통 모달·문서형 폼·신청/상세 결재란, 사원 맥락 줄·근태 캘린더 요약·주간 패널·내 정보, 관리 화면의 완료된 변경을 반영했다. 5단계 전체 완료를 뜻하지 않는다.
- 확인 시점 Claude 작업트리의 미커밋 `frontend/src/design/screens.css`는 편집 중이므로 포함하지 않았다. 원래 작업트리와 사용자 파일은 보존했다.
- 일반 제품에는 기존에 없는 공개 전용 `DemoAccountSwitcher.tsx` 변경을 추가하지 않았다. 일반 헤더의 사원 정보와 공개 헤더의 합성 회사 표시를 각각 보존했고 CSS 검사는 각 제품에 실제 있는 파일을 검사한다.
- 공개 계정 전환의 작은 모달 크기 변경은 공개본에 반영했다. 기존 공개 로그인·계정 보호·CSRF·권한과 main의 저장 중 사유 변경 차단을 유지했다.
- Java·DB 마이그레이션·배포/실행 설정·package/lock은 변경하지 않았다. 공개 통합은 기존 보안을 보존하며 DB V17을 유지한다.

## 통합 검토에서 보완한 두 오류

1. 예정 시간 요약이 시·분만 읽어 서버의 `time(3)` 입력에서 초·밀리초를 버렸다. 근무·휴게 차감과 월·주 합산을 정수 밀리초로 수행하고 기존 시·분 표시에서만 분 미만을 내린다. 실제 근태 계산 엔진의 정책을 변경한 것은 아니다. [고정 근무 입력](../design/fixed-schedule.md)과 [계산 정밀도 규칙](../rules/calculation.md)을 따른다.
2. 예외 정정·예외 취소를 관리자가 대리 작성한 경우에도 상세 결재란이 대상 사원을 `기안`으로 표시했다. 제공되는 이름의 의미에 맞게 상세의 역할을 `대상 사원`으로 바꿨다. 본인 신청 작성기의 기안 표시는 유지했다.
