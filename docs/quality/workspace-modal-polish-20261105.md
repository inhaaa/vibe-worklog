# WorkLog 화면 정돈과 업무 모달

2026-11-04 시작, 2026-11-05 Asia/Seoul 검증. [실행 계획과 인터페이스](../superpowers/plans/2026-11-04-workspace-modal-polish.md)를 따른다.

## 변경

- `App.tsx`가 배경 화면·조회 조건·컴포넌트를 보존하고 업무 상세를 `Modal`에 표시한다. 직원 상세/권한/인사/근무 배정, 조직 상세/조직장, 근무 템플릿, 결재선 배정, 직원별 정책, 연차 원장/귀속, 신청 작성/정정/상세, 계산 근거에 적용한다. 사이드 메뉴 탐색·일반 목록 조회와 직접 URL 접근은 페이지 방식으로 유지한다.
- X·닫기·Esc, Tab/Shift+Tab 내부 순환, 원래 버튼/링크 초점 복귀, 배경 스크롤 잠금, 내부 스크롤을 제공한다. 미저장 입력을 확인하고 저장/신청 미리보기 중에는 닫기를 막는다. 저장 뒤 배경을 다시 조회하며 목록 조회만 실패하면 저장 성공과 구분해 안내한다. 401/403/재인증은 모달과 배경의 개인정보를 함께 제거한다.
- 내정보 기본사항은 신원·입사·추가 정보 표, 주소는 주소/연락 표로 나눈다. 발령·가족·학력·자격·어학은 건수·표·빈 상태를 통일한다. 미등록·비해당·0개월의 의미와 키보드 탭 탐색을 보존한다.
- 직원 헤더의 사진·소속·사번·재직 상태와 인사 항목을 정돈한다. 신청·미리보기·상세·결재·예외 정정의 카드, 라벨, 요약, 간격·가독성을 맞춘다. 기존 작성 단계와 입력·원천 근거·명령·개정·CSRF를 보존한다.
- 공통 업무 폼·표·버튼에 밝은 중립 표면과 인디고 색상, 44px 조작 영역, 모바일 입력16px, reduced-motion을 적용한다. 신규 의존성·설정·서버 API·DB 스키마 변경은 없다.

Windows sandbox의 Node 사용자 디렉터리 접근 EPERM은 동일 명령을 일반 사용자 권한으로 실행해 해결했다. 최초 전체 병렬 실행의 대형50행 테스트2개 timeout은 worker2로 재실행해 통과했으며 제품/테스트 시간 제한을 늘리지 않았다. 모달 통합에서 발견한 실제 정정 URL 누락, 저장 성공 후 목록 실패의 혼동, 동적 모달 초점 유실, 중복 신청 모달을 수정하고 회귀 테스트를 추가했다.

합성 UI 서버는 ignored `target/ui-polish-preview-20261104`에서 loopback만 사용하고 실제 DB를 사용하지 않는다. GET fixture와 신청 미리보기만 제공하며 다른 POST는 실제 저장하지 않는다. 이 브라우저 검증을 실제 서버 업무 HTTP 검증으로 확대하지 않는다. 모바일 입력 후 native confirm을 여는 과정은 IAB 제어 시간 초과로 전체 수동 흐름을 마치지 못했으며 미저장 확인은 자동 테스트로 검증했다.

## 공개 반영 상태와 미실시 범위

최신 공개 기준은 [상단 메뉴 배포](https://github.com/inhaaa/vibe-worklog/blob/61694f2/docs/quality/public-toolbar-deploy-20261104.md)의 `b074d42`·V17이다. 기존 보안·공유 계정 보호와 상단 메뉴 변경을 보존하기 위해 별도 `codex/ui-polish-public-20261104` 작업트리에서 개발 커밋 `c912f60`을 통합했다. 코드 충돌은 없었고 README에는 기존 공개 기록과 신규 UI 기록을 함께 보존했다.

전체/회귀/빌드 로그와 자산 SHA는 ignored `target/ui-polish-deploy-20261104`에 보관했다. 실제 서버 앱 교체, V17·비UI JAR 항목 보존, 기존 서비스 영향과 공개 업무 HTTP 검증은 배포 담당자의 후속 증거로 별도 기록한다.

초기 준비 시점에는 Hostinger 관리 화면 세션은 확인했지만 웹 콘솔은 서버 로그인 화면이고 SSH22는 실제 연결 시간 초과였다. 서버 로그인 완료 전에는 공개 앱·DB·설정을 변경하지 않았다. UI 구현 완료와 공개 배포 완료를 구분한다.

Java/DB 통합·실제 업무 HTTP·부하·취약점 재검사는 이 UI 변경에서 재실행하지 않았다. 기존 업무 계약과 알려진 운영 한계는 유지한다. 기존 untracked 공통 시트 설계 문서는 변경/커밋 대상에서 제외한다.
