# 입사 첫해 월별 연차와 퇴사 잔여 정산 검증

담당자와 직원이 서로 다른 계정으로 로그인해 같은 발생일, 소명 사유, 부여·사용·정산 일수를 대조한다. 날짜는 서울 기준이며, 사원과 출근 자료는 모두 검증용 가상 자료다. [업무 기준](../superpowers/plans/2026-11-22-employment-leave.md) · [로컬 재현 방법](../development/local.md#입사-후-월별-발생과-퇴사-잔여-검증)

## 인수 시나리오

| 대상 | 담당자·결재자가 하는 일 | 직원이 확인할 수량과 근거 |
| --- | --- | --- |
| E101, 4월 15일 입사 | 5월 15일·6월 15일·7월 15일 발생분을 개근·미개근·개근으로 각각 확정 | +1일, 0일, +1일과 각 판단 사유. 합계 2일 |
| E202, 4월 15일 입사 | 이미 1일을 부여한 원천에 첫 개근월을 연결 | 5월 15일 기초 +1일, 5월 18일 사용 −1일, 첫 개근월 추가 0일. 같은 원천과 확인 사유, 잔여 0일 |
| E101, 7월 16일 오전 반차 | 직원이 신청하고 독립 결재자가 승인 | 대기 중 2일, 승인 후 −0.5일과 잔여 1.5일 |
| E101, 7월 17일 마지막 재직일 | 월별 부여 2일과 사용 0.5일을 대조하고 1.5일 정산 | 원장 정산 −1.5일, 사용 가능 0일. 담당자와 같은 마지막 재직일·정산 일수·사유 |
| E101, 7월 18일 | 퇴사 다음 날 기존 세션과 새 로그인을 각각 시도 | 개인 원장 접근 회수 |

E101의 첫 달은 소정근로 22일 모두 출근이 확인됐다. 둘째 달은 소정 21일 중 출근 20일이 확인됐고 6월 1일이 미확인이었다. 담당자가 가상 회사 확인서를 대조해 미개근 사유를 입력했다. 셋째 달은 소정 22일 모두 출근이 확인됐다. 근태자료상의 미확인 1일과 담당자가 최종 확정한 판단이 직원 원장에도 함께 표시된다. [브라우저 업무 흐름](../../scripts/verify-employment-leave.cjs) · [합성 근태·휴가 자료](../../src/test/java/kr/tna/EmploymentLeaveBrowser.java)

Chrome 157.0.8103.52에서 PC 1440×900과 모바일 터치 에뮬레이션 390×844를 각각 새 가상 회사로 실행했다. 두 환경 모두 7단계가 통과했고 화면을 각 10장 기록했다. 화면에서 읽은 근거·잔여·영수증과 퇴사 후 접근 결과가 일치했다. 데이터 조회 재시도는 양쪽 모두 0회였다. 실제 앱이 내려준 `app.js`와 로컬 배포용 빌드의 SHA-256은 `a855ea7586a31ca00ef167e80db622189596998a55dda5348e74cfef2ba36bc7`이다.

공통 브라우저 도구를 변경한 뒤 이전 V37 회사별 연차 시나리오도 별도 가상 회사에서 재실행했다. PC에서 부여·이월·소멸, 반차 승인 후 14.5일, 취소 승인 후 15일 복원까지 8단계가 통과했다. [기존 연차 회귀 시나리오](../../scripts/verify-annual-leave-cycle.cjs)

## 경계와 재현

- 월말·윤년 입사, 첫 1년 사용기한, 회사 회계연도 경계와 처음 확정한 시작월을 확인한다. 기초 오등록을 수기로 감액한 양과 기존에 연결한 개근월은 추가로 연결할 수 있는 일수에서 제외한다. 실제 승인된 휴가는 사용 이력과 원부여 근거를 함께 대조한다. [월별 산정 통합 테스트](../../src/test/java/kr/tna/EmploymentAccrualIT.java)
- 마지막 재직일에는 담당자 미리보기의 묶음별 수량으로 원장을 차감한다. 정산 대상이 0일이어도 영수증이 남는다. 1주년 이후에는 회사 회계 원장과 입사일 기준 발생·사용을 대조한 사유를 남긴다. [퇴사 정산 통합 테스트](../../src/test/java/kr/tna/LeaveExitServiceIT.java)
- 두 개의 로컬 마이그레이션은 기초 원장과 기존 업무 역할을 보존하고, 월별 판단·정산 영수증을 회사별로 보관한다. 다른 회사 자료, 자기 처리, 미처리 신청·취소, 미리보기 이후 원장 변경, 중복 명령과 원장 쓰기 중 오류를 검증한다. [권한·직원 원장 HTTP 테스트](../../src/test/java/kr/tna/EmploymentLeaveWebIT.java) · [기존 데이터 마이그레이션](../../src/test/java/kr/tna/CodeMigrationUpgradeIT.java)
- 담당자·직원 화면과 기존 자료 업그레이드 21건, 월별 산정·신청 관련 56건, 퇴사 정산·수기 조정 관련 60건이 각각 통과했다. 각 묶음에는 공통 휴가 신청 검증이 들어 있다. 원천 연결 후의 감액은 단건 저장, 일괄 미리보기, 일괄 저장 각각에서 거절됐고 같은 요청의 다른 사원 잔여도 보존됐다.
