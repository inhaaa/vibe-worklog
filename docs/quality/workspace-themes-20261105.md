# 차콜·블루 테마와 화면 전면 개편 검증

2026-11-05, Asia/Seoul. [화면 계약](../design/workspace-themes.md)과 [공통 디자인](../../design.md)을 따른다.

**개발본 구현·로컬 검증 완료. 공개 데모 미반영.** 공개 서버의 SSH 접속은 연결 시간 초과로 실패했으며 서버·DB·공개 이미지는 변경하지 않았다. 이 문서의 브라우저 결과는 loopback 합성 UI를 대상으로 한다.

## 변경 범위

- `tokens.css`, `base.css`, `WorkspacePolish.css`, 기존 `static/app.css`: 흰 표면·한국어 시스템 글꼴·표·입력·버튼·간격·상태·초점 규칙을 통합했다. 외부 폰트를 추가하지 않았다.
- `ThemeSwitcher.tsx`, `App.tsx`: 차콜/블루 선택, 브라우저 저장·복원, 저장소 차단 예외 처리, 본문 건너뛰기를 추가했다. 테마는 권한·사용자·업무 자료를 바꾸지 않는다.
- 사원 헤더·메뉴·모달, 내정보·신청·결재, 로그인·소개 화면을 선과 정보 행 중심으로 재구성했다. 중첩 카드·gradient·장식 상태점·불필요한 링크 화살표를 정리했다.
- 모바일 신청 요약표는 각 항목명과 값을 세로로 배치한다. 기존 표·열 제목·값·접근성 역할을 유지한다.
- 업무 엔드포인트·폼 필드·handler·CSRF·버전·명령·권한·DB 스키마를 유지했다. 기존 미추적 `2026-10-29-common-sheet-design.md`는 수정하지 않았다.

전체 테스트 중 링크 접근성 이름과 달력 상태 구분자에 대한 기존 테스트 실패를 발견했다. 테스트를 변경하지 않고 기존 접근성/표시 계약을 복원하여 최종 통과했다. 신규 모바일 표 테스트의 필수 `csrf` 타입 입력 누락도 수정해 타입 검사까지 확인했다. 초기 담당 테스트의 비동기 초점1건은 단독 재실행 및 최종 전체 실행에서 통과했다.

Hallmark가 요구하는 렌더 도구는 `target/hallmark-tools`에만 임시 설치했다. Puppeteer Core 25.16.0, Apache-2.0, Node >=22.12.0을 공식 registry와 [설치 안내](https://pptr.dev/guides/installation)로 확인했다. 설치된 Node22.14.0과 호스트 Chrome으로 검증했으며 앱 package/lockfile·전역 도구·설정은 변경하지 않았다.

## 문구·자료 보존

업무 설명·주의문·값은 유지했다. 화면 제목/경로와 중복인 작은 선행 라벨23개는 통합했고 원문은 `.hallmark/copy-changes.json`에 기록했다. 날짜·유형·연도처럼 의미가 있는 라벨은 일반 본문으로 유지했다. 링크의 장식 화살표를 정리했으며 기존 테스트가 사용하는 `내 근무 일정 →` 접근성 이름은 보존했다. 달력의 독립 상태 표시는 기존 `유형 · 상태` 그대로다.

소개 화면의 가짜 브라우저 장식·중복 브랜드 문자만 제거하고 기존 업무 안내·요일 예시를 평평한 목록으로 배치했다. `데모 살펴보기 ↗`/`사번으로 로그인 →`는 화살표만 정리했다. 사원 이미지는 기존 URL/이니셜을 사용하며 새 사진·고객 지표·후기·로고는 추가하지 않았다. 따라서 교체를 기다리는 사진 슬롯은 없다.

## 로컬 증거와 한계

- `target/hallmark-tools/.hallmark/compare.html`: 대표 화면 전후 비교, `before/`·`shots/` 각15장.
- `target/hallmark-tools/artifacts/`: 업무 검증 JSON, 프로필·모달8장, 모바일 요약표 캡처/검증.
- `target/hallmark-tools/auth-verification.json` 및 `auth-*.png`: 인증8화면.
- `.hallmark/preflight.json`, `log.json`: 사전 조사·디자인 선택·검증 기록.

실제 DB·Java 통합·업무 저장/승인 POST·부하·보안 전수 검사는 재실행하지 않았다. 공개본은 별도의 보안·상단 메뉴 변경을 포함하므로 개발본 자산으로 바로 대체하지 않는다. 공개 통합·배포·공개 HTTP 확인은 미완료이며 `worklog.inhaaa.com`에 반영됐다고 주장하지 않는다.
