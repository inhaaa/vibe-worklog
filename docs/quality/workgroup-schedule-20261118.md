# 근무조별 근무설정 로컬 검증

[승인 명세](../superpowers/specs/2026-11-18-workgroup-schedule-design.md)와 [구현 계획](../superpowers/plans/2026-11-18-workgroup-schedule.md)을 기준으로 검증했다. 로컬 전용 PostgreSQL과 합성 계정을 사용했다.

| 확인한 흐름 | 관찰 결과 |
| --- | --- |
| 담당자 시간코드 등록 | 09:00~18:00 근무에 복수 예정 휴게를 등록했다. 18:30~21:00 연장 허용 구간에서 20:00~20:15 예정 휴게를 빼 최대 135분으로 표시됐다. |
| 근무조 개정 | 11월 23일부터 적용하는 근무조에 직원을 배정했다. 시간코드를 10시 출근으로 개정한 뒤에도 기존 조원에게 09시가 표시됐다. 11월 24일자 근무조 개정의 영향 명단에서 사원을 확인하고 발행하자 그날부터 10시가 표시됐다. 사원을 다시 배정하는 조작은 없었다. |
| 사원·담당자 재조회 | 직원 캘린더와 담당자 배정 이력에서 전날과 적용일을 다시 확인했다. 최초 발령에서 입사 예정일을 바꾸면 해당 날짜의 조·시간코드·출퇴근 시간과 선택할 개정이 함께 바뀌었다. |
| 브라우저 | PC Chrome 1440×900과 모바일 터치 에뮬레이션 390×844에서 각각 별도 사원으로 등록부터 재조회까지 9개 흐름을 확인했다. 최종 빌드에서 각각 6개 화면을 다시 확인했다. 확인한 화면에서 페이지 가로 넘침이나 JavaScript 페이지 오류는 없었다. |

자동 검증은 기존 고정배정·최초 발령 ID 보존, 연도 경계의 조 개정과 전입·전출, 같은 명령의 재시도, 충돌 시 일괄 배정 전체 취소, 진행 중인 당일 근무 보호를 포함한다. 휴가에서는 신청 후 근무 기준이 바뀌면 최종 승인을 재검토하며, 이미 승인된 건은 원래 차감과 변경 전후 시간표를 조회한다.

| 최종 자동 검증 | 결과 |
| --- | --- |
| Maven 전체 회귀 | 단위 189건, PostgreSQL 통합 721건 통과. 실패·오류·건너뜀 0건. |
| 프런트엔드 | TypeScript 검사와 Vite 빌드 성공. Vitest 54개 파일의 608건이 최종 순차 실행에서 모두 통과했다. |
| 재검증 | 신규 테이블 5개를 RLS 검증 대상에 추가했다. 다른 회귀와 병렬 실행할 때 기존 코드·조직 시트 두 건에서 그리드를 찾지 못했다. 해당 두 파일의 67건을 단독으로 재검증한 뒤 전체 화면 회귀도 통과했다. |

검증은 로컬 개발본을 대상으로 했다. 공개 데모 배포는 보류했다.
