# 가상 사원 인사정보·단일 헤더·업무 메뉴 검증

기준일: 2026-11-02, Asia/Seoul. [설계](../superpowers/specs/2026-11-02-demo-personnel-header-design.md)와 [실행 계획](../superpowers/plans/2026-11-02-demo-personnel-header.md)을 따른다. 이 문서는 로컬 구현·검증 결과이며 실제 공개 반영은 별도 배포 결과에 기록한다.

## 구현

- `EmployeeHeader`의 업무 탭과 children을 제거했다. 사진·이름·조직·사번·재직 상태와 생년월일·직급·직책·직무·입사일을 한 카드에 표시한다. 기존 공통 API·사진 실패 대체 표시를 재사용한다.
- 업무별 3단계 메뉴에 SVG 아이콘·활성 상위 메뉴/세부 메뉴 강조·구분선·키보드 포커스를 적용했다. 경로·역할·모바일 메뉴와 상단 긴 이름 표시 계약은 유지한다.
- `demo/personnel-20261102`에 AI로 개별 생성한 가상 성인 사진 4장과 고정 인사정보·원본/정규화 SHA·생성 프롬프트를 보존했다. 실제 개인정보나 외부 인물 사진을 사용하지 않았다.
- 명시적 유지보수 CLI `public-demo-personnel-fill`만 추가했다. public-demo 단독 프로필·전용 DB·일반 앱 역할/RLS·고정 4인/계정/조직/manifest와 당일을 확인하고, 인사 4행·상태 4행·감사 5행만 원자적으로 추가한다. 기존 자료/부분 등록을 덮어쓰지 않으며 동일 재실행은 전체 내용 일치 시에만 no-op이다. 일반 API의 공유 계정 보호를 완화하지 않는다.
- 새 라이브러리·마이그레이션은 없다. V16을 유지한다. 일반 개발 브랜치에는 공통 UI 변경만 반영하며 공개 유지보수 CLI/자료는 공개 브랜치에 둔다.

## 공개 반영 전 조건과 한계

공개 서버에서 현재 V16/빈 인사 자료와 기존 서비스를 다시 읽고, 검증된 새 이미지의 Linux JRE 사진 정규화 SHA를 확인한 뒤 WorkLog 앱만 중지한다. fresh 전용 백업·제한된 독립 DB 실제 복원·기존 전체 행/권한 대조를 통과한 다음 13행 추가와 두 번째 실행의 전체 no-op을 확인하고 앱을 반영한다. 공개 HTTP·인증 사진 4장·PC/390px와 기존 서비스/Caddy를 확인하기 전에는 배포 완료로 해석하지 않는다.

이 변경의 새 장시간 부하·전체 취약점 스캔·실제 개인정보/메일·상용 운영 수용은 수행하지 않았다. 이전 성적을 이번 변경의 새 실행 결과로 표현하지 않는다.

실제 공개 후속: `725373d`·V16·가상4인 등록과 백업/독립 복원·정확13행 추가/재실행 무변경·공개98+4항목/사진4/PC·390px·기존 서비스 보존을 마쳤다. [최종 실제 배포 결과](public-demo-personnel-deploy-20261102.md)를 따른다.
