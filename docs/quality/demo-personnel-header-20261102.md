# 단일 사원 헤더·업무 메뉴 및 공개 가상 자료 후속

2026-11-02, Asia/Seoul. 사용자의 후속 요청으로 공통 헤더의 별도 탭을 제거하고 사진·이름/조직/사번·재직 상태·생년월일·직급·직책·직무·입사일을 하나의 카드에 항상 표시한다. 기존 업무별3단계 메뉴에는 아이콘·활성 조상/세부 메뉴 강조·구분선·키보드 포커스를 적용한다. 역할·경로와 모바일 상단 표시 규칙은 유지한다.

공개 별도 소스 `725373d`에는 같은 UI와 명시적 단발 유지보수 CLI·고정 가상4인 자료/사진을 포함했다. 사진은 AI로 생성한 가상 성인4장이다. 재직2명·휴직1명·정직1명으로 채웠으며 기존 이름·소속·입사일·계정 권한·근태 자료는 유지한다. 공개 유지보수 CLI와 가상 자료는 일반 개발 브랜치에 복사하지 않았다.
