# ADR-0002: 검토용 단일 XLSX의 최소 OOXML 출력

- 결정일: 2026-10-24
- 상태: MVP 검토용 다운로드에 한정해 채택
- 근거: [보고 계약](../design/worktime-results.md), [기술 기준선](0001-technology-baseline.md)

## 결정과 대안

MVP는 텍스트와 정수 밀리초의 검토용 단일 시트만 출력한다. 수식·서식 템플릿·파일 업로드·외부 링크·매크로가 필요하지 않아 JDK ZipOutputStream과 고정 OOXML 패키지를 사용한다. Apache POI 도입안은 풍부한 스프레드시트 처리를 제공하지만 지금 범위에는 새 전이 의존성 없이 제한된 출력으로 충분하다. CSV는 null/단위/수식 처리와 XLSX 요구를 충족하는 별도 형식이므로 대체하지 않는다.

사용자 문자열은 inlineStr, 정수만 numeric 셀로 기록한다. XML 유효 문자·길이·행/열 한도·고정 경로/시트명을 검증한다. null은 미확정 텍스트로 내보내고0으로 치환하지 않는다. 결과·전체 경계 주 근거·필터·생성 시점·tenant·snapshot ID를 고정한다.

## 한계와 검증

라이브러리나 범용 Excel 엔진을 만들지 않는다. 업로드·다중 서식·수식 등 범위가 생기면 POI의 당시 버전·호환성·고지를 다시 확인한다. JDK 외 새 라이선스 의존성은 추가하지 않는다. ZIP의 OOXML 파트·XML 이스케이프·수식 비생성·정수/null·불변 스냅샷·권한·HTTP MIME을 테스트한다. 이 결정은 Excel 데스크톱 전 버전의 상호운용성 보증을 뜻하지 않는다.
