# vibe-attendance

AI-Assisted Development와 Vibe Coding으로 만드는 HR 근태관리 시스템의 초기 기획 저장소입니다.

## 목적

국내 중소기업의 근태 업무를 지원하는 웹 멀티테넌트 SaaS를 개인 프로젝트로 기획합니다. 주요 고객은 상시근로자 10~300명 사업장이며, 서비스 지원 대상은 최소 5인 이상 사업장으로 계획합니다. 이 범위는 개별 법령의 적용 여부를 일괄 판단하는 기준이 아닙니다.

고객별 설정을 제공하되 개별 코드 커스터마이징은 지양합니다. 공개 법령·공식 자료·일반 HR 지식을 바탕으로 독립 개발하며, 기존 회사의 비공개 코드와 문서는 사용하지 않습니다.

## 주요 기능 후보

아래는 검토 후보이며, 구현된 기능이나 확정된 MVP 범위가 아닙니다.

- 출퇴근 기록과 개인 근태·근로시간 조회
- 휴가·근태·추가 근무·정정 신청 및 승인
- 조직·사원 설정, 근태 계산·집계·마감과 데이터 출력
- 서비스 운영자의 고객·요금제·사용량 관리

고정근무 기반부터 우선 검토합니다. MVP 범위, 지원 근무제, 출퇴근 인증 방식은 미정이며, 상세 후보와 초기 제외 범위는 [초기 기획서](docs/kickoff.md)에서 관리합니다.

## 기술 스택 계획

| 구분 | 계획 |
| --- | --- |
| Backend | Java 25 LTS, Spring Boot 4.1.x, Spring Security, MyBatis 4.x, Maven + Wrapper |
| 데이터베이스 | PostgreSQL 18, Flyway |
| Frontend | Thymeleaf, htmx, HTML·CSS·JavaScript, 반응형 웹, PWA |
| 테스트 | JUnit 5, Testcontainers, PostgreSQL 통합 테스트 |
| 인프라 | Docker, Docker Compose, Caddy, Linux VPS |
| 기타 | Apache POI, Spring Boot Actuator |

위 버전과 기술은 사용자 계획이며 출시·지원 상태 및 상호 호환성 검증이 완료되지 않았습니다. 특히 Spring Boot 4.1.x, MyBatis 4.x, JUnit 5를 포함한 의존성 조합은 Phase 4 진입 전에 공식 문서로 확인합니다.

## 아키텍처 요약

```text
브라우저 → HTTPS → Caddy → Spring Boot(화면 + 업무) → PostgreSQL
```

모듈형 모놀리스로 하나의 애플리케이션과 데이터베이스를 공유하는 구조를 계획합니다. 테넌트 데이터 격리는 `tenant_id`, SQL 필터, PostgreSQL RLS를 함께 사용하는 방식으로 설계할 예정입니다. PC·모바일 반응형 화면과 PWA를 검토합니다.

단일 애플리케이션 구조가 단일 서버의 처리량을 보장하지는 않으며, 수용 가능한 부하는 추후 검증합니다.

## AI 활용 개발 방식

AI는 기획·설계·코드 작성·리뷰·테스트를 돕는 개발 지원 도구로 활용합니다. 이는 서비스에 AI 기능을 탑재한다는 뜻이 아닙니다. AI 산출물은 사람이 검토하고 테스트로 확인합니다.

구현 단계에서는 스키마·인터페이스를 먼저 정의하는 SDD와 테스트 작성 → 구현 → 리팩토링 순서의 TDD를 적용합니다.
